# Statistik (statistics)

Statistics with Python, from describing data to testing hypotheses.

| Chapter | Content |
|---|---|
| 1 | Descriptive statistics: measures of location and spread, charts, two-dimensional data |
| 2 | Estimation: point estimators and their quality criteria |
| 3 | Statistical significance and p-values |

Interactive Python cells (pandas, Matplotlib, SciPy), exercises checked automatically and a cheat sheet. German and English.

- Rendered site: `docs/` (serve it locally, see the [overview](../README.md)).
- Build: `python build_multilingual_site.py --no-serve`
- Source: `gitlab.ruhr-uni-bochum.de/ctm/tutorials`, folder `Statistik`
