Ein interaktives Tutorial für Einsteiger

Willkommen!

Statistik begegnet uns überall: in Zeitungsartikeln über Umfragen, in medizinischen Studien, beim Sportreporting und in der Wirtschaft. Doch was steckt eigentlich dahinter? Wie kann man aus einer Handvoll Messungen verlässliche Aussagen über die Welt machen?

Dieses Tutorial gibt dir eine solide Einführung in die Grundlagen der Statistik – von der Beschreibung von Daten bis zum Schluss von einer Stichprobe auf die Grundgesamtheit. Dabei nutzen wir Python, um Konzepte nicht nur zu verstehen, sondern auch direkt auszuprobieren.

Als durchgehender roter Faden dient uns der Palmer-Pinguins-Datensatz – ein realer Datensatz mit Messungen von drei Pinguinarten aus der Antarktis. Er ist anschaulich, vielfältig und macht statistische Methoden greifbar.

Unser Datensatz: Die Palmer-Pinguine

Der Datensatz enthält Messdaten von 344 Pinguinen dreier Arten, gesammelt auf drei Inseln des Palmer-Archipels in der Antarktis. Für jeden Pinguin liegen folgende Merkmale vor:

  • Schnabellänge und Schnabeltiefe (in mm)
  • Flossenlänge (in mm)
  • Körpermasse (in g)

# Welcome! {#willkommen}

Statistics is everywhere: in newspaper articles about surveys, in medical studies, in sports reporting and in business. But what is actually behind it? How can you make reliable statements about the world from a handful of measurements?

This tutorial gives you a solid introduction to the fundamentals of statistics – from describing data to drawing conclusions from a sample about the population. We use **Python** not only to understand concepts, but also to try them out directly.

::: {.callout-tip}
**No prior knowledge required!** This tutorial only assumes basic mathematics (school level). Programming experience is helpful but not necessary – a separate Python introduction page helps you get started.
:::

---

## What to expect {#was-dich-erwartet}

The tutorial is divided into two chapters:

| Chapter | Content | Key question |
|---------|--------|-----------|
| **1. Descriptive statistics** | Describing & summarizing data | *What does my data look like?* |
| **2. Estimation theory** | Inferring from a dataset to the population | *What holds beyond my sample?* |

A third chapter on **hypothesis tests** (*Is a difference due to chance or real?*) is in preparation. Section 2.5 on significance and p-values already gives a first glimpse.

Our common thread is the **Palmer Penguins dataset** – a real dataset with measurements of three penguin species from Antarctica. It is vivid and varied, and it makes statistical methods tangible.

---

## Our dataset: the Palmer penguins {#unser-datensatz-die-palmer-pinguine}

![The three penguin species of the dataset: Adélie, Chinstrap and Gentoo](https://allisonhorst.github.io/palmerpenguins/reference/figures/lter_penguins.png)

The dataset contains measurements of **344 penguins** of three species, collected on three islands of the Palmer Archipelago in Antarctica. For each penguin the following variables are available:

- **Bill length** and **bill depth** (in mm)
- **Flipper length** (in mm)
- **Body mass** (in g)
- **Island**, **species** and **sex**

Why this dataset? It is an excellent example because it contains real measurements, offers different types of variables (metric, categorical) and directly raises interesting questions: *Do the species differ? Are there relationships between the variables?*

In this tutorial we use the following Python libraries:

- **`pandas`** – for reading, managing and filtering datasets (our "spreadsheet")
- **`matplotlib`** – for creating graphics and charts
- **`scipy`** – for statistical computations and tests
- **`numpy`** – for basic numerical operations

::: {.callout-python}
**Python tip:** You don't have to install Python – all code blocks in this tutorial run directly in the browser! If you want to dig deeper, have a look at the [Python basics page](grundlagen.qmd).

### What the buttons on the code blocks do {#was-die-knöpfe-an-den-codeblöcken-können}

- **Run code** (or **Shift + Enter**): Python runs in the background, the page stays usable. If something takes too long, cancel it with **Stop**.
- <i class="fa-solid fa-arrows-rotate"></i> resets a block to the original code, <i class="fa-regular fa-copy"></i> copies the code.
- **+ Code block** adds another empty block below a block for experimenting.
- **Your code is saved:** Whatever you write in editable blocks is kept in this browser and is back on your next visit (but it is not run automatically). "💾 Saved" then appears next to "Editable"; with <i class="fa-solid fa-trash-can"></i> you delete the saved version. In the <i class="fa-solid fa-gear"></i> menu at the top right you can switch saving off or delete everything saved.
- **Charts** get a toolbar for zooming, panning and downloading (PNG/SVG/PDF).
- Some exercises are **checked automatically**: for programming exercises with **Check**, hidden tests run on your code; for calculation exercises, your result is checked immediately.
