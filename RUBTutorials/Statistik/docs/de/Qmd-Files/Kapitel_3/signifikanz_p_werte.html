2.5 Statistische Signifikanz & p-Werte

Das Problem

Angenommen, eine Pharmafirma behauptet, ihr neues Medikament sei in 60 % der Fälle wirksam. In einer Studie mit 40 Patienten zeigen 26 eine Verbesserung, also 65 %. Belegt das eine Wirksamkeit von mehr als 60 %, oder ist das nur Zufall?

Oder stell dir vor: Adélie-Pinguine hatten früher eine mittlere Schnabellänge von 38 mm. Unsere Stichprobe zeigt 38,8 mm. Ist das ein echter Unterschied, oder nur Zufall?

Statistische Hypothesentests geben uns ein formales Werkzeug, um solche Fragen zu beantworten – und dabei die Wahrscheinlichkeit für Fehlentscheidungen zu kontrollieren.

Nullhypothese und Alternativhypothese

Jeder statistische Test beginnt mit der Formulierung von zwei konkurrierenden Hypothesen:

HinweisNullhypothese und Alternativhypothese

Die Nullhypothese H_0 beschreibt den “Status quo” oder “kein Effekt / kein Unterschied”. Sie wird nur verworfen, wenn die Daten starke Evidenz dagegen liefern.

Die Alternativhypothese H_1 beschreibt den vermuteten Effekt oder Unterschied. Wird H_0 verworfen, entscheidet man sich für H_1.

TippWarum ist H_0 asymmetrisch?

Man kann H_0 verwerfen (mit kontrollierbarer Fehlerwahrscheinlichkeit), aber man kann H_0 nie “beweisen”. Ein Test kann nur zeigen: “Die Daten sind mit H_0 kaum vereinbar.” Deshalb formuliert man das, was man zeigen will, als H_1.

Beispiele

Fragestellung H_0 H_1
Hat sich die Schnabellänge erhöht? \mu \leq 38 mm \mu > 38 mm
Unterscheiden sich zwei Gruppen? \mu_1 = \mu_2 \mu_1 \neq \mu_2
Wirkt das Medikament in mehr als 60 % der Fälle? p \leq 0{,}6 p > 0{,}6

Einseitige Tests: H_1 hat eine Richtung (z.B. \mu > 38).

Zweiseitige Tests: H_1 hat keine Richtung (z.B. \mu \neq 38).

Fehler 1. und 2. Art

Bei einer Testentscheidung können zwei Arten von Fehlern auftreten:

H_0 nicht verworfen H_0 verworfen
H_0 wahr Richtige Entscheidung ✓ Fehler 1. Art (α)
H_0 falsch Fehler 2. Art (β) Richtige Entscheidung ✓
HinweisFehler 1. und 2. Art

Fehler 1. Art (Typ-I-Fehler, α): H_0 wird verworfen, obwohl sie wahr ist. → “Falscher Alarm” / false positive

Fehler 2. Art (Typ-II-Fehler, β): H_0 wird nicht verworfen, obwohl sie falsch ist. → “Verpasster Effekt” / false negative

Das Signifikanzniveau \alpha ist die vorgegebene Obergrenze für den Fehler 1. Art. Typisch: \alpha = 0{,}05 (5 %).

VorsichtDas Dilemma

Macht man \alpha sehr klein (z.B. 0,001), wird der Fehler 1. Art selten – aber dann steigt der Fehler 2. Art. Bei fester Stichprobengröße lassen sich nicht beide Fehler gleichzeitig beliebig klein machen.

In der Praxis: Man fixiert \alpha und wählt den Test mit der höchsten Teststärke (auch Power, 1-\beta: die Wahrscheinlichkeit, einen echten Effekt zu finden).

Fehler 1. und 2. Art zum Anfassen

Die türkise Kurve ist die Verteilung der Teststatistik, wenn H_0 gilt, die dunkelblaue gestrichelte Kurve die Verteilung, wenn ein Effekt der Größe \delta vorliegt (H_1). Der Test verwirft H_0, sobald die Teststatistik rechts vom kritischen Wert c liegt. Ziehe den schwarzen Punkt c auf der Achse und stelle \delta mit dem Schieberegler ein.

  • Rote Fläche = \alpha: H_0 gilt, trotzdem landet die Teststatistik rechts von c (falscher Alarm).
  • Orange Fläche = \beta: H_1 gilt, trotzdem landet die Teststatistik links von c (Effekt verpasst).

Probiere aus:

  1. Ziehe c nach rechts, bis \alpha \approx 1\,\% ist. Was passiert mit \beta?
  2. Stelle c auf etwa 1{,}64 (\alpha = 5\,\%). Ab welchem \delta erreicht die Teststärke 80\,\%?
  3. Setze \delta = 0. Wie groß ist die Teststärke dann?
TippAuflösung
  1. Bei c \approx 2{,}33 ist \alpha \approx 1\,\%, dafür steigt \beta von etwa 20\,\% auf etwa 43\,\%. Weniger falsche Alarme kosten mehr verpasste Effekte.
  2. Ab \delta \approx 2{,}49.
  3. Genau \alpha. Ohne Effekt kann der Test nur durch einen falschen Alarm verwerfen.
HinweisWas dahintersteckt

\delta ist der Abstand der beiden Verteilungen, gemessen in Standardfehlern. Beim Test auf einen Mittelwert ist \delta = \dfrac{\mu_1 - \mu_0}{\sigma/\sqrt{n}}. Ein größerer Effekt oder eine größere Stichprobe schiebt die H_1-Kurve nach rechts. So lässt sich \beta senken, ohne \alpha zu erhöhen. Das ist der einzige Ausweg aus dem Dilemma.

Die Teststatistik und der p-Wert

Das allgemeine Testprinzip

  1. Formuliere H_0 und H_1.
  2. Wähle ein Signifikanzniveau \alpha (z.B. 0,05).
  3. Berechne aus den Daten eine Teststatistik T (eine Zahl, die misst, wie weit die Daten von H_0 entfernt sind).
  4. Berechne den p-Wert = Wahrscheinlichkeit, eine mindestens so extreme Teststatistik zu beobachten, wenn H_0 wahr wäre.
  5. Entscheidung: Verwirf H_0, wenn p \leq \alpha.

Definition des p-Werts

Hinweisp-Wert

Der p-Wert ist die Wahrscheinlichkeit, unter Annahme von H_0 eine Teststatistik zu beobachten, die mindestens so extrem ist wie die tatsächlich beobachtete.

Ein kleiner p-Wert bedeutet: Die Daten sind unter H_0 sehr unwahrscheinlich → starke Evidenz gegen H_0.

Korrekte Interpretation des p-Werts

VorsichtHäufige Fehler bei der p-Wert-Interpretation

Falsch: “Der p-Wert ist die Wahrscheinlichkeit, dass H_0 wahr ist.”

Falsch: “p = 0,03 bedeutet: H_1 ist zu 97 % wahr.”

Falsch: “p < 0,05 bedeutet, der Effekt ist groß oder praktisch relevant.”

Richtig: “p ist die Wahrscheinlichkeit, bei gültiger H_0 eine mindestens so extreme Teststatistik zu beobachten wie die tatsächlich gemessene.”

Das Vorgehen: 5 Schritte

Standardablauf eines Hypothesentests:

  1. Hypothesen aufstellen: H_0 und H_1 formulieren.
  2. Signifikanzniveau festlegen: \alpha wählen (meist 0,05).
  3. Teststatistik berechnen: aus den Daten.
  4. p-Wert berechnen: Wahrscheinlichkeit unter H_0.
  5. Entscheidung treffen: Verwirf H_0, wenn p \leq \alpha.

Zurück zu den Einstiegsfragen

Das Medikament

Die Firma möchte zeigen, dass ihr Medikament in mehr als 60 % der Fälle wirkt: H_0: p \leq 0{,}6, H_1: p > 0{,}6. Die Teststatistik ist die Anzahl X der Patienten mit Verbesserung. Gilt H_0 mit p = 0{,}6, ist X \sim \text{Bin}(40;\ 0{,}6) und man erwartet 24 Verbesserungen. Der p-Wert ist die Wahrscheinlichkeit für mindestens so viele Verbesserungen wie beobachtet:

\text{p-Wert} = P(X \geq 26) \approx 0{,}317

Mit einem p-Wert von 0{,}317 > 0{,}05 wird H_0 nicht verworfen. 26 von 40 passen gut zu einer Wirksamkeit von genau 60 %. Mehr als 60 % belegt die Studie also nicht. Gegen p = 0{,}5 getestet ergibt sich dagegen ein p-Wert von P(X \geq 26) \approx 0{,}040 \leq 0{,}05: Dass das Medikament besser wirkt als ein Münzwurf, zeigen die Daten schon.

Die Schnabellänge

Für die n = 151 Adélie-Pinguine im Datensatz ist \bar{x} = 38{,}79 mm und s = 2{,}66 mm. Getestet wird H_0: \mu \leq 38 gegen H_1: \mu > 38 mit der Teststatistik

t = \frac{\bar{x} - 38}{s/\sqrt{n}}.

Sie misst, wie viele Standardfehler der Mittelwert über 38 mm liegt. Berechne Standardfehler und t:

Teststatistik von Hand
\(\text{SE} =\) mm, \(t =\)
TippLösungsweg
  • \text{SE} = s/\sqrt{n} = 2{,}66/\sqrt{151} \approx 2{,}66/12{,}29 \approx 0{,}2165 mm
  • t = (38{,}79 - 38)/0{,}2165 \approx 3{,}65

Unter H_0 ist t t-verteilt mit n - 1 = 150 Freiheitsgraden (wie beim t-Intervall in 2.4). Der p-Wert ist P(T \geq 3{,}65) \approx 0{,}0002 \leq 0{,}05, also wird H_0 verworfen. Ein Unterschied von 0{,}79 mm ist bei 151 Tieren kein Zufall mehr. In Python: stats.ttest_1samp(adelie_bill, popmean=38, alternative='greater').

Statistische vs. praktische Signifikanz

Ein häufiges Missverständnis: Ein statistisch signifikantes Ergebnis ist nicht automatisch praktisch relevant.

Links: n = 10, wahrer Unterschied von 10 Einheiten – statistisch nicht signifikant (zu wenig Daten für die große Streuung).

Rechts: n = 10.000, wahrer Unterschied von 0,1 Einheiten – statistisch signifikant, aber praktisch irrelevant.

TippFaustregel

Ein statistisch signifikantes Ergebnis zeigt nur: Die Daten passen schlecht zu H_0. Bei großen Stichproben reicht dafür schon ein winziger Effekt. Ob der Effekt praktisch wichtig ist, muss inhaltlich beurteilt werden – zum Beispiel über die Effektgröße (Cohens d, relative Differenz etc.).

## Die Teststatistik und der p-Wert

### Das allgemeine Testprinzip

1. Formuliere $H_0$ und $H_1$.
2. Wähle ein Signifikanzniveau $\alpha$ (z.B. 0,05).
3. Berechne aus den Daten eine **Teststatistik** $T$ (eine Zahl, die misst, wie weit die Daten
   von $H_0$ entfernt sind).
4. Berechne den **p-Wert** = Wahrscheinlichkeit, eine mindestens so extreme Teststatistik zu
   beobachten, wenn $H_0$ wahr wäre.
5. Entscheidung: Verwirf $H_0$, wenn $p \leq \alpha$.

### Definition des p-Werts

::: {.callout-note icon=false}
## p-Wert

Der **p-Wert** ist die Wahrscheinlichkeit, unter Annahme von $H_0$ eine Teststatistik zu
beobachten, die mindestens so extrem ist wie die tatsächlich beobachtete.

Ein kleiner p-Wert bedeutet: Die Daten sind unter $H_0$ sehr unwahrscheinlich → starke Evidenz
gegen $H_0$.
:::


## Häufige Fehler bei der p-Wert-Interpretation

**Falsch:** "Der p-Wert ist die Wahrscheinlichkeit, dass $H_0$ wahr ist."

**Falsch:** "p = 0,03 bedeutet: $H_1$ ist zu 97 % wahr."

**Falsch:** "p < 0,05 bedeutet, der Effekt ist groß oder praktisch relevant."

**Richtig:** "p ist die Wahrscheinlichkeit, bei gültiger $H_0$ eine mindestens so extreme
Teststatistik zu beobachten wie die tatsächlich gemessene."
:::

## Das Vorgehen: 5 Schritte

::: {.callout-rechnen appearance="minimal"}
**Standardablauf eines Hypothesentests:**

1. **Hypothesen aufstellen:** $H_0$ und $H_1$ formulieren.
2. **Signifikanzniveau festlegen:** $\alpha$ wählen (meist 0,05).
3. **Teststatistik berechnen:** aus den Daten.
4. **p-Wert berechnen:** Wahrscheinlichkeit unter $H_0$.
5. **Entscheidung treffen:** Verwirf $H_0$, wenn $p \leq \alpha$.
:::

## Zurück zu den Einstiegsfragen

### Das Medikament

Die Firma möchte zeigen, dass ihr Medikament in mehr als 60 % der Fälle wirkt: $H_0: p \leq 0{,}6$, $H_1: p > 0{,}6$. Die Teststatistik ist die Anzahl $X$ der Patienten mit Verbesserung. Gilt $H_0$ mit $p = 0{,}6$, ist $X \sim \text{Bin}(40;\ 0{,}6)$ und man erwartet $24$ Verbesserungen. Der p-Wert ist die Wahrscheinlichkeit für mindestens so viele Verbesserungen wie beobachtet:

$$\text{p-Wert} = P(X \geq 26) \approx 0{,}317$$

```{pyodide-python}
from scipy import stats

# P(X >= 26) = P(X > 25) für X ~ Bin(40; 0,6)
print(stats.binom.sf(25, 40, 0.6))
# Zum Vergleich: gegen p = 0,5 (Münzwurf)
print(stats.binom.sf(25, 40, 0.5))
```

Mit einem p-Wert von $0{,}317 > 0{,}05$ wird $H_0$ nicht verworfen. 26 von 40 passen gut zu einer Wirksamkeit von genau 60 %. Mehr als 60 % belegt die Studie also nicht. Gegen $p = 0{,}5$ getestet ergibt sich dagegen ein p-Wert von $P(X \geq 26) \approx 0{,}040 \leq 0{,}05$: Dass das Medikament besser wirkt als ein Münzwurf, zeigen die Daten schon.

Für die $n = 151$ Adélie-Pinguine im Datensatz ist $\bar{x} = 38{,}79$ mm und $s = 2{,}66$ mm. Getestet wird $H_0: \mu \leq 38$ gegen $H_1: \mu > 38$ mit der Teststatistik

## Statistische vs. praktische Signifikanz

Ein häufiges Missverständnis: Ein **statistisch signifikantes** Ergebnis ist nicht automatisch
**praktisch relevant**.

**Links:** n = 10, wahrer Unterschied von 10 Einheiten – statistisch nicht signifikant (zu wenig Daten
für die große Streuung).

**Rechts:** n = 10.000, wahrer Unterschied von 0,1 Einheiten – statistisch signifikant, aber praktisch
irrelevant.

::: {.callout-tip}
## Faustregel

Ein statistisch signifikantes Ergebnis zeigt nur: **Die Daten passen schlecht zu $H_0$.** Bei großen
Stichproben reicht dafür schon ein winziger Effekt. Ob der Effekt praktisch wichtig ist, muss inhaltlich
beurteilt werden – zum Beispiel über die Effektgröße (Cohens d, relative Differenz etc.).
:::

## Zusammenfassung

| Begriff | Bedeutung |
|---------|-----------|
| **Nullhypothese** $H_0$ | "Kein Effekt" – wird verworfen oder beibehalten |
| **Alternativhypothese** $H_1$ | Der vermutete Effekt |
| **Signifikanzniveau** $\alpha$ | Maximale erlaubte Fehler-1.-Art-Wahrscheinlichkeit |
| **Teststatistik** | Zusammenfassung der Daten in eine Zahl |
| **p-Wert** | P(mindestens so extreme Daten \| $H_0$ wahr) |
| **Fehler 1. Art** | $H_0$ verworfen, obwohl wahr (Rate ≤ α) |
| **Fehler 2. Art** | $H_0$ nicht verworfen, obwohl falsch (Rate = β) |
| **Teststärke** $1-\beta$ | Wahrscheinlichkeit, einen echten Effekt zu entdecken |

## The problem {#das-problem}

Suppose a pharmaceutical company claims its new drug is effective in 60 % of cases. In a study
with 40 patients, 26 show an improvement, i.e. 65 %. Does this show an effectiveness of more than
60 %, or is it just chance?

Or imagine: Adélie penguins used to have a mean bill length of 38 mm. Our sample shows 38.8 mm.
Is that a real difference, or just chance?

**Statistical hypothesis tests** give us a formal tool to answer such questions – while
controlling the probability of wrong decisions.

---

## Null hypothesis and alternative hypothesis {#nullhypothese-und-alternativhypothese}

Every statistical test starts by stating two competing hypotheses:

::: {.callout-note icon=false}
## Null hypothesis and alternative hypothesis

The **null hypothesis** $H_0$ describes the "status quo" or "no effect / no difference".
It is only rejected if the data provide strong evidence against it.

The **alternative hypothesis** $H_1$ describes the suspected effect or difference.
If $H_0$ is rejected, one decides in favour of $H_1$.
:::

::: {.callout-tip}
## Why is $H_0$ asymmetric?

You can reject $H_0$ (with a controllable error probability), but you can never "prove"
$H_0$. A test can only show: "The data are hardly compatible with $H_0$."
That is why what you want to show is stated as $H_1$.
:::

### Examples {#beispiele}

| Question | $H_0$ | $H_1$ |
|---------------|--------|-------|
| Has the bill length increased? | $\mu \leq 38$ mm | $\mu > 38$ mm |
| Do two groups differ? | $\mu_1 = \mu_2$ | $\mu_1 \neq \mu_2$ |
| Is the drug effective in more than 60 % of cases? | $p \leq 0.6$ | $p > 0.6$ |

**One-sided tests:** $H_1$ has a direction (e.g. $\mu > 38$).

**Two-sided tests:** $H_1$ has no direction (e.g. $\mu \neq 38$).

---

## Type I and type II errors {#fehler-1.-und-2.-art}

Two kinds of errors can occur in a test decision:

| | $H_0$ not rejected | $H_0$ rejected |
|---|---|---|
| **$H_0$ true** | Correct decision ✓ | **Type I error** (α) |
| **$H_0$ false** | **Type II error** (β) | Correct decision ✓ |

::: {.callout-note icon=false}
## Type I and type II errors

**Type I error** (α): $H_0$ is rejected although it is true.
→ "False alarm" / false positive

**Type II error** (β): $H_0$ is not rejected although it is false.
→ "Missed effect" / false negative

The **significance level** $\alpha$ is the chosen upper bound for the type I error.
Typical: $\alpha = 0.05$ (5 %).
:::

::: {.callout-caution}
## The dilemma

If you make $\alpha$ very small (e.g. 0.001), type I errors become rare – but type II errors
become more likely. With a fixed sample size, both errors cannot be made arbitrarily small at the same time.

In practice: fix $\alpha$ and choose the test with the highest **power**
($1-\beta$: the probability of finding a real effect).
:::

## The test statistic and the p-value {#die-teststatistik-und-der-p-wert}

### The general testing principle {#das-allgemeine-testprinzip}

1. State $H_0$ and $H_1$.
2. Choose a significance level $\alpha$ (e.g. 0.05).
3. Compute a **test statistic** $T$ from the data (a number that measures how far the data
   are from $H_0$).
4. Compute the **p-value** = probability of observing a test statistic at least as extreme,
   if $H_0$ were true.
5. Decision: reject $H_0$ if $p \leq \alpha$.

### Definition of the p-value {#definition-des-p-werts}

::: {.callout-note icon=false}
## p-value

The **p-value** is the probability, assuming $H_0$, of observing a test statistic that is
at least as extreme as the one actually observed.

A small p-value means: the data are very unlikely under $H_0$ → strong evidence
against $H_0$.
:::


### Interpreting the p-value correctly {#korrekte-interpretation-des-p-werts}

::: {.callout-caution}
## Common mistakes in interpreting p-values

**Wrong:** "The p-value is the probability that $H_0$ is true."

**Wrong:** "p = 0.03 means: $H_1$ is 97 % true."

**Wrong:** "p < 0.05 means the effect is large or practically relevant."

**Right:** "p is the probability, if $H_0$ holds, of observing a test statistic at least as
extreme as the one actually measured."
:::

## The procedure: 5 steps {#das-vorgehen-5-schritte}

::: {.callout-rechnen appearance="minimal"}
**Standard procedure of a hypothesis test:**

1. **State hypotheses:** formulate $H_0$ and $H_1$.
2. **Fix the significance level:** choose $\alpha$ (usually 0.05).
3. **Compute the test statistic:** from the data.
4. **Compute the p-value:** probability under $H_0$.
5. **Decide:** reject $H_0$ if $p \leq \alpha$.
:::

## Back to the opening questions {#zurück-zu-den-einstiegsfragen}

### The drug {#das-medikament}

The company wants to show that its drug works in more than 60 % of cases: $H_0: p \leq 0.6$, $H_1: p > 0.6$. The test statistic is the number $X$ of patients who improve. If $H_0$ holds with $p = 0.6$, then $X \sim \text{Bin}(40;\ 0.6)$ and one expects $24$ improvements. The p-value is the probability of at least as many improvements as observed:

$$\text{p-value} = P(X \geq 26) \approx 0.317$$

```{pyodide-python}
from scipy import stats

# P(X >= 26) = P(X > 25) for X ~ Bin(40; 0.6)
print(stats.binom.sf(25, 40, 0.6))
# For comparison: against p = 0.5 (coin toss)
print(stats.binom.sf(25, 40, 0.5))
```

With a p-value of $0.317 > 0.05$, $H_0$ is not rejected. 26 out of 40 fit an effectiveness of exactly 60 % well. So the study does not show more than 60 %. Tested against $p = 0.5$, however, the p-value is $P(X \geq 26) \approx 0.040 \leq 0.05$: the data do show that the drug works better than a coin toss.

### The bill length {#die-schnabellänge}

For the $n = 151$ Adélie penguins in the data set, $\bar{x} = 38.79$ mm and $s = 2.66$ mm. We test $H_0: \mu \leq 38$ against $H_1: \mu > 38$ with the test statistic

$$t = \frac{\bar{x} - 38}{s/\sqrt{n}}.$$

It measures how many standard errors the mean lies above 38 mm. Compute the standard error and $t$:

```{math-exercise}

#| tolerance: 1%
```

::: {.callout-tip collapse="true" title="Solution steps"}
- $\text{SE} = s/\sqrt{n} = 2.66/\sqrt{151} \approx 2.66/12.29 \approx 0.2165$ mm
- $t = (38.79 - 38)/0.2165 \approx 3.65$

Under $H_0$, $t$ follows a t-distribution with $n - 1 = 150$ degrees of freedom (as for the t-interval in 2.4). The p-value is $P(T \geq 3.65) \approx 0.0002 \leq 0.05$, so $H_0$ is rejected. A difference of $0.79$ mm is no longer chance with 151 animals. In Python: `stats.ttest_1samp(adelie_bill, popmean=38, alternative='greater')`.
:::

## Statistical vs. practical significance {#statistische-vs.-praktische-signifikanz}

A common misconception: a **statistically significant** result is not automatically
**practically relevant**.

```{python}
#| echo: false
#| eval: true
np.random.seed(42)
# Large n: small true difference becomes significant
n_large = 10000
mu1, mu2 = 100.0, 100.1  # True difference: 0.1 units
sigma = 2.0

t_stat, p = stats.ttest_ind(
    np.random.normal(mu1, sigma, n_large),
    np.random.normal(mu2, sigma, n_large)
)

fig, axes = plt.subplots(1, 2, figsize=(10, 3.8))

# Small n: large difference, not significant
n_small = 10
x1 = np.random.normal(100, 15, n_small)
x2 = np.random.normal(110, 15, n_small)
t2, p2 = stats.ttest_ind(x1, x2)

ax = axes[0]
ax.boxplot([x1, x2], tick_labels=['Group 1', 'Group 2'])
ax.set_title(f'n={n_small} per group, true difference 10\np = {p2:.3f} → {"sig." if p2<0.05 else "NOT sig."}',
             fontsize=10)
ax.set_ylabel('Measurement')

ax2 = axes[1]
x1b = np.random.normal(mu1, sigma, n_large)
x2b = np.random.normal(mu2, sigma, n_large)
t_large, p_large = stats.ttest_ind(x1b, x2b)
ax2.boxplot([x1b, x2b], tick_labels=['Group 1', 'Group 2'])
ax2.set_title(f'n={n_large} per group, true difference 0.1\np = {p_large:.4f} → {"sig." if p_large<0.05 else "NOT sig."}',
              fontsize=10)

plt.suptitle('Statistical ≠ practical significance', fontsize=11, y=1.02)
plt.tight_layout()
plt.show()
```

**Left:** n = 10, true difference of 10 units – not statistically significant (too little data
for the large spread).

**Right:** n = 10,000, true difference of 0.1 units – statistically significant, but practically
irrelevant.

::: {.callout-tip}
## Rule of thumb

A statistically significant result only shows: **the data fit $H_0$ poorly.** With large
samples, even a tiny effect is enough for that. Whether the effect matters in practice has to be
judged on the content – for example via the effect size (Cohen's d, relative difference etc.).
:::

## Summary {#zusammenfassung}

| Term | Meaning |
|---------|-----------|
| **Null hypothesis** $H_0$ | "No effect" – rejected or kept |
| **Alternative hypothesis** $H_1$ | The suspected effect |
| **Significance level** $\alpha$ | Maximum allowed probability of a type I error |
| **Test statistic** | The data summarised in one number |
| **p-value** | P(data at least as extreme \| $H_0$ true) |
| **Type I error** | $H_0$ rejected although true (rate ≤ α) |
| **Type II error** | $H_0$ not rejected although false (rate = β) |
| **Power** $1-\beta$ | Probability of detecting a real effect |
