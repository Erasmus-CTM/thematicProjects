## Schleifen

**For-Schleifen** wiederholen Code für eine bestimmte Anzahl von Durchläufen:

```{pyodide-python}
for i in range(5):
    print(i)
```

**Probiere:** Ändere `range(5)` zu `range(1, 6)`. Dann zu `range(0, 10, 2)`. Was ändert sich?

```{pyodide-python}
for i in range(5):   # ← Ändere range(...)!
    print(i)
```

Man kann auch über Listenelemente iterieren:

```{pyodide-python}
noten = [2, 1, 3, 2, 4]
summe = 0
for note in noten:
    summe = summe + note

print(f"Summe: {summe}, Durchschnitt: {summe / len(noten):.2f}")
```

**Jetzt du:** Zähle mit einer for-Schleife, wie viele Noten ≤ 2 sind. Starte mit `anzahl = 0` und erhöhe es bei jeder „guten" Note um 1. **Überprüfen** testet dein Ergebnis.

```{py-exercise}

#| caption: Gute Noten zählen
noten = [2, 1, 3, 2, 1, 4, 2, 3, 1]
anzahl = 0
# Dein Code hier: for note in noten: if note <= 2: ...
print(anzahl)

## TESTS ##

assert anzahl == 6, "Nicht ganz: Es sind 6 Noten ≤ 2. Zählst du auch die 2er mit (<= statt <)?"
assert noten == [2, 1, 3, 2, 1, 4, 2, 3, 1], "Die Liste noten soll unverändert bleiben."
```

<summary>Lösung anzeigen</summary>

```{pyodide-python}
def fakultaet(n):
    if n == 0:
        return 1
    result = 1
    i = 1
    while i <= n:
        result = result * i
        i = i + 1
    return result

print(fakultaet(5))    # 120
print(fakultaet(10))   # 3628800
```

</details>

## scipy

**scipy** stellt Wahrscheinlichkeitsverteilungen und statistische Testverfahren bereit. Das Untermodul `scipy.stats` wird vor allem in Kapitel 2 genutzt.

```{pyodide-python}
from scipy import stats
import numpy as np

# Eine Normalverteilung an die Daten anpassen
daten = np.array([39.1, 39.5, 40.3, 36.7, 39.3, 38.9, 41.1, 42.0, 37.8])

# Mittelwert und Standardabweichung der Normalverteilung schätzen
mittelwert, std = np.mean(daten), np.std(daten)
print(f"Geschätzter Mittelwert: {mittelwert:.2f}")
print(f"Geschätzte Std.-Abw.:   {std:.2f}")

# Wahrscheinlichkeit, einen Wert ≤ 40 zu beobachten
p = stats.norm.cdf(40, loc=mittelwert, scale=std)
print(f"P(X ≤ 40): {p:.3f}")
```

**Python-Tipp:** `from scipy import stats` – beachte die etwas andere Import-Syntax. Damit sind `stats.norm`, `stats.t` etc. direkt verfügbar. Die Funktionen werden in den Kapiteln erklärt, sobald sie gebraucht werden.

## NumPy

**NumPy** (Numerical Python) is the basis for numerical computations. It provides arrays – efficient lists of numbers to which you can apply mathematical operations directly.

```{pyodide-python}
import numpy as np

# Create arrays
bill_length = np.array([39.1, 39.5, 40.3, 36.7, 39.3, 38.9, 41.1])

# Operations on the whole array
print(f"Mean:           {np.mean(bill_length):.2f} mm")
print(f"Std. deviation: {np.std(bill_length):.2f} mm")
print(f"Minimum:        {np.min(bill_length):.2f} mm")
print(f"Maximum:        {np.max(bill_length):.2f} mm")
```

::: {.callout-python}
**Python tip:** `np.mean()`, `np.std()`, `np.min()`, `np.max()` – you will need these four functions in almost every chapter. NumPy is always imported with `import numpy as np`. Caution: by default, `np.std()` computes the **uncorrected** standard deviation (divisor $n$), pandas' `.std()` the corrected one (divisor $n-1$). [Chapter 1.5](Kapitel_1/kennzahlen_streuung.qmd) explains the difference.

### Counts, missing values and groups

Three tools you need constantly in chapter 1: **counting frequencies** (`value_counts()`), **removing missing values** (`dropna()`) and **computing per group** (`groupby()`). Real datasets such as the penguins often have gaps; here the bill of the fourth animal was not measured (`None`, shown as `NaN` in pandas):

```{pyodide-python}
#| read-only: true
import pandas as pd

data = pd.DataFrame({
    "species": ["Adélie", "Adélie", "Chinstrap", "Gentoo", "Gentoo"],
    "bill_mm": [39.1, 39.5, 46.5, None, 50.0],
    "mass_g":  [3750, 3800, 3500, 4500, 5700]
})

# How often does each species occur?
print(data["species"].value_counts())

# Missing values: .mean() skips them, .dropna() removes them
print(data["bill_mm"].mean())
print(data["bill_mm"].dropna())

# Mean per group
print(data.groupby("species")["mass_g"].mean())
```

## scipy

**scipy** provides probability distributions and statistical test procedures. The submodule `scipy.stats` is used mainly in chapter 2.

```{pyodide-python}
from scipy import stats
import numpy as np

# Fit a normal distribution to the data
data = np.array([39.1, 39.5, 40.3, 36.7, 39.3, 38.9, 41.1, 42.0, 37.8])

# Estimate the mean and standard deviation of the normal distribution
mean, std = np.mean(data), np.std(data)
print(f"Estimated mean:      {mean:.2f}")
print(f"Estimated std. dev.: {std:.2f}")

# Probability of observing a value ≤ 40
p = stats.norm.cdf(40, loc=mean, scale=std)
print(f"P(X ≤ 40): {p:.3f}")
```

::: {.callout-python}
**Python tip:** `from scipy import stats` – note the slightly different import syntax. This makes `stats.norm`, `stats.t` etc. directly available. The functions are explained in the chapters as soon as they are needed.
:::
