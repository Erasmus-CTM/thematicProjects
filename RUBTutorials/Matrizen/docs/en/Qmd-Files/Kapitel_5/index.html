5. Application: Geometric Transformations

```quizdown

# Wann ist eine Matrix **invertierbar** (regulär)?
1. [ ] Wenn sie quadratisch ist und nur positive Zahlen enthält.
1. [ ] Wenn ihre Determinante gleich 0 ist.
1. [x] Wenn ihre Determinante ungleich 0 ist.
1. [ ] Wenn sie mehr Zeilen als Spalten hat.

> Denk an die normale Division bei Zahlen: Durch welche Zahl darf man niemals teilen? Die Determinante spielt hier eine ähnliche Rolle für die Inverse.

# Was berechnet `np.linalg.matrix_rank(A)`?
1. [ ] Die Anzahl der Elemente in der Matrix.
1. [x] Die Anzahl der linear unabhängigen Zeilen/Spalten.
1. [ ] Den höchsten Wert in der Matrix.
1. [ ] Die Dimension (z.B. 2D).

> Es geht um den Informationsgehalt: Wie viele Zeilen sind "echt neu" und nicht nur Kopien oder Mischungen der anderen?

# Bringe die Code-Zeilen in die richtige Reihenfolge, um die Determinante einer Matrix zu berechnen.
1. `import numpy as np`
2. `M = np.array([[2, 0], [0, 2]])`
3. `det = np.linalg.det(M)`
4. `print(det)`

> Erst Import, dann Daten, dann die Funktion aus dem Submodul `linalg`.

# Geometrisch gesehen: Was bedeutet es, wenn die Determinante einer $2 \times 2$ Matrix **0** ist?
- [x] Die von den Vektoren aufgespannte Fläche ist 0 (die Vektoren liegen auf einer Linie).
- [ ] Die Vektoren stehen senkrecht aufeinander.
- [ ] Die Fläche ist unendlich groß.
- [x] Die von den Vektoren aufgespannte Fläche kollabiert (ist "platt").

> Die Determinante ist ein Skalierungsfaktor für Flächen. Was bleibt von einer Fläche übrig, wenn der Faktor 0 ist?

# Was ist das Ergebnis von $A \cdot A^{-1}$ (Matrix mal ihre Inverse)?
1. [ ] Eine Nullmatrix.
1. [x] Die Einheitsmatrix ($E$).
1. [ ] Die Matrix $A$ selbst.
1. [ ] Das Skalar 1.

> Was kommt bei normalen Zahlen heraus, wenn man $5 \cdot \frac{1}{5}$ rechnet? Das Äquivalent dazu bei Matrizen ist gesucht.

# Python-Check: Was gibt dieser Code aus?
~~~python
A = np.eye(3)
print(np.linalg.det(A))
~~~
1. [ ] 0.0
1. [ ] 3.0
1. [x] 1.0
1. [ ] Error

> `eye` erstellt die Einheitsmatrix. Ändert diese Matrix die Größe einer Fläche, wenn man sie anwendet?

# Welche Dimension hat das Ergebnis von `(2x5) @ (5x3)`?
1. [ ] `(5, 5)`
1. [ ] `(2, 5)`
1. [x] `(2, 3)`
1. [ ] Error

> Die inneren Zahlen müssen "passen" und verschwinden dann. Was bleibt übrig?

# Code-Puzzle: Berechne die Inverse einer Matrix `A` und prüfe das Ergebnis!
1. `inv_A = np.linalg.inv(A)`
2. `check = A @ inv_A`
3. `print(np.round(check))`

> Erst invertieren, dann Probe durch Multiplikation. Das Ergebnis sollte die Einheitsmatrix sein (wir runden wegen möglicher Fließkommafehler).

# Was macht `liste[::-1]` mit einer Python-Liste?
1. [ ] Löscht das letzte Element.
1. [ ] Gibt das letzte Element aus.
1. [x] Dreht die Reihenfolge der Liste um.
1. [ ] Sortiert die Liste absteigend.

> Das ist Slicing mit Schrittweite -1. Wir laufen also rückwärts durch die Liste.

# Wie erstellst du eine $3 \times 3$ Matrix voller Einsen?
1. [ ] `np.eye(3)`
1. [x] `np.ones((3, 3))`
1. [ ] `np.fill(3, 1)`
1. [ ] `np.array([1, 1, 1])`

> Der Funktionsname sagt genau, welche Zahl drinstehen soll (Englisch für "Einsen"). `eye` wäre nur die Diagonale.

# Verständnisfrage: Warum nutzen wir Computer für die Inverse, statt sie von Hand zu rechnen?
1. [ ] Weil Computer bessere Handschrift haben.
1. [x] Weil der Rechenaufwand extrem schnell wächst (bei großen Matrizen fast unmöglich von Hand).
1. [ ] Weil es mathematisch von Hand nicht geht.
1. [ ] Weil Computer dabei nie Rundungsfehler machen.

> Bei kleinen Matrizen geht es noch, aber der Aufwand explodiert mit der Größe (kubisches Wachstum).

# Was passiert hier (Broadcasting)?
~~~python
M = np.array([[10, 10], [20, 20]])
print(M + 1)
~~~
1. [ ] Error, man kann Zahl nicht auf Matrix addieren.
1. [ ] `[11, 11, 21, 21]`
1. [x] `[[11, 11], [21, 21]]`
1. [ ] `[[10, 11], [20, 21]]`

> NumPy ist nett: Wenn du eine einzelne Zahl (`1`) auf eine Matrix addierst, wird sie einfach auf *jedes* Element draufgerechnet.

# Theorie-Check: Wenn der Rang einer $3 \times 3$ Matrix nur 2 ist, dann...
- [x] ... ist die Matrix singulär (nicht invertierbar).
- [ ] ... ist die Matrix invertierbar.
- [ ] ... hat sie 3 linear unabhängige Zeilen.
- [x] ... ist die Determinante 0.

> Wenn der Rang kleiner ist als die Dimension (Voller Rang), fehlt Information. Die Matrix ist "plattgedrückt".
```
