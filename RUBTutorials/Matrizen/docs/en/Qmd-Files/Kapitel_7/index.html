```quizdown

# LGS-Logik: Ein lineares Gleichungssystem $A \cdot x = b$ hat genau eine eindeutige Lösung, wenn...
1. [ ] ... $b$ gleich 0 ist.
1. [x] ... die Matrix $A$ invertierbar ist (Determinante ≠ 0).
1. [ ] ... die Matrix $A$ mehr Zeilen als Spalten hat.
1. [ ] ... die Matrix $A$ singulär ist.

> Damit du den Punkt $x$ eindeutig findest, muss die Transformation umkehrbar sein.

# Python-Praxis: Welcher Befehl löst das Gleichungssystem $Ax = b$ am stabilsten?
1. [ ] `x = inv(A) * b`
1. [ ] `x = A / b`
1. [x] `x = np.linalg.solve(A, b)`
1. [ ] `x = solve(b, A)`

> `solve` ist schneller und genauer als die explizite Berechnung der Inversen.

# Geometrie-Check: Wenn du eine Matrix $M$ auf einen Vektor $v$ anwendest ($M \cdot v$), was passiert im Normalfall?
1. [ ] Der Vektor behält immer seine Richtung.
1. [ ] Der Vektor behält immer seine Länge.
1. [x] Der Vektor ändert meistens sowohl Richtung als auch Länge.
1. [ ] Der Vektor wird immer zum Nullvektor.

> Das ist der Standardfall bei linearen Transformationen (Drehstreckung, Scherung etc.).

# Code-Puzzle: Wie prüfst du, ob eine Lösung `x` für das LGS `A @ x = b` korrekt ist?
1. `x = np.linalg.solve(A, b)`
2. `b_check = A @ x`
3. `print(np.allclose(b, b_check))`

> Wir rechnen die Probe: Wir setzen $x$ in die Gleichung ein und schauen, ob wieder $b$ herauskommt. `allclose` hilft bei Rundungsfehlern.

# Verständnisfrage: Was ist ein "homogenes" Gleichungssystem?
1. [ ] Ein System, bei dem alle Zahlen gleich sind.
1. [x] Ein System, bei dem die rechte Seite 0 ist ($A \cdot x = 0$).
1. [ ] Ein System, das nur aus Einsen besteht.
1. [ ] Ein System ohne Lösung.

> Homogen bedeutet hier, dass der "Zielvektor" der Nullvektor ist. Die triviale Lösung ist immer $x=0$.

# Determinanten-Wissen: Was weißt du über eine Matrix, deren Determinante 0 ist?
1. [x] Sie bildet den Raum auf eine niedrigere Dimension ab (z.B. Fläche auf Linie).
1. [ ] Sie vergrößert alle Vektoren.
1. [ ] Sie ist besonders gut invertierbar.
1. [ ] Sie ist eine Einheitsmatrix.

> Wenn der "Flächeninhalt" (Determinante) zu 0 wird, wurde der Raum "plattgedrückt". Information geht verloren.

# Matrix-Arithmetik: Gilt für Matrizen die binomische Formel $(A+B)^2 = A^2 + 2AB + B^2$?
1. [ ] Ja, immer.
1. [x] Nein, im Allgemeinen nicht.
1. [ ] Nur wenn $A$ die Einheitsmatrix ist.

> Vorsicht! Da $A \cdot B ≠ B \cdot A$ ist, gilt: $(A+B)(A+B) = A^2 + AB + BA + B^2$. Man darf $AB$ und $BA$ nicht einfach zusammenfassen.

# Code-Verständnis: Was bedeutet der Fehler `LinAlgError: Singular matrix` bei `np.linalg.solve`?
1. [ ] Die Matrix enthält Text statt Zahlen.
1. [ ] Die Matrix ist zu groß.
1. [x] Die Matrix ist nicht invertierbar (Determinante 0), es gibt keine eindeutige Lösung.
1. [ ] Du hast NumPy nicht importiert.

> "Singulär" ist das Fachwort für "Kaputt für Invertierung". Die Geraden liegen parallel (kein Schnittpunkt) oder aufeinander (unendlich viele).

# Transformationen: Wenn eine Matrix $M$ nur eine Skalierung (Streckung) bewirkt (z.B. `3 * eye(2)`), was passiert mit den Vektoren?
1. [ ] Sie drehen sich um 90 Grad.
1. [x] Sie behalten ihre Richtung, werden aber länger/kürzer.
1. [ ] Sie werden alle auf 0 gesetzt.

> Das ist ein Spezialfall! Hier ist *jeder* Vektor ein Eigenvektor (Spoiler für das nächste Kapitel!).

# Python-Slicing Refresher: Du hast eine Matrix `A`. Wie holst du dir die komplette 2. Zeile?
1. [ ] `A[:, 1]`
1. [x] `A[1, :]`
1. [ ] `A[2, :]`
1. [ ] `A[0, 2]`

> Index 1 ist die zweite Zeile. Der Doppelpunkt an zweiter Stelle heißt "alle Spalten".

# Geometrie: Welche Matrix spiegelt einen Punkt an der y-Achse?
1. [x] `np.array([[-1, 0], [0, 1]])`
1. [ ] `np.array([[1, 0], [0, -1]])`
1. [ ] `np.array([[0, 1], [1, 0]])`
1. [ ] `np.array([[-1, 0], [0, -1]])`

> Bei der Spiegelung an der y-Achse wechselt die x-Koordinate das Vorzeichen, die y-Koordinate bleibt gleich.

# Logik-Check: Wenn $A \cdot x = 2 \cdot x$ ist, was kannst du über die Matrix $A$ und den Vektor $x$ sagen?
1. [ ] $A$ muss die Zahl 2 sein.
1. [ ] $x$ muss der Nullvektor sein.
1. [x] Die Matrix $A$ wirkt auf $x$ wie eine einfache Verdopplung (Skalierung).
1. [ ] Das ist mathematisch unmöglich.

> Genau das ist die Definition, die wir im nächsten Kapitel suchen: Eine Matrix, die sich wie ein einfacher Faktor verhält.
```
