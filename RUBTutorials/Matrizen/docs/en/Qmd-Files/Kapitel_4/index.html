# Welche Dimension hat das Ergebnis der Matrix-Multiplikation `(3x5) @ (5x2)`?
1. [ ] `(3, 5)`
1. [ ] `(5, 5)`
1. [x] `(3, 2)`
1. [ ] Error

> Die inneren Dimensionen (5) müssen übereinstimmen und fallen weg. Übrig bleiben die Äußeren (Zeilen von A, Spalten von B).

# Was ist der Unterschied zwischen `A * B` und `A @ B` in NumPy?
1. [ ] Es gibt keinen, beides ist Matrixmultiplikation.
1. [x] `*` ist elementweise Multiplikation, `@` ist die mathematische Matrixmultiplikation.
1. [ ] `@` ist für Vektoren, `*` ist für Matrizen.
1. [ ] `*` ist schneller, aber ungenauer.

> Das ist der häufigste Fehler in NumPy! `*` rechnet stumpf "Zelle mal Zelle", `@` rechnet "Zeile mal Spalte".

# Was passiert bei `[1, 2] + [3, 4]` (normale Python-Listen)?
1. [ ] `[4, 6]`
1. [x] `[1, 2, 3, 4]`
1. [ ] `Error`
1. [ ] `10`

> Listen verhalten sich wie Text: "Hallo" + "Welt" wird auch aneinandergehängt. Matrizen addieren mathematisch.

# Bringe die Schritte in die richtige Reihenfolge, um $(A \cdot B)^T$ zu berechnen.
1. `A` und `B` definieren.
2. `C = A @ B` (Multiplikation)
3. `D = C.T` (Transposition)
4. `print(D)`

> Punkt-vor-Strich: Erst muss das Produkt existieren, bevor du es spiegeln (transponieren) kannst.

# Warum ist `A @ B` meistens nicht dasselbe wie `B @ A`?
- [x] Weil Matrixmultiplikation nicht kommutativ ist.
- [ ] Weil NumPy Rundungsfehler macht.
- [x] Weil oft nur eine der beiden Reihenfolgen überhaupt definiert ist (z.B. 2x3 mal 3x4 geht, 3x4 mal 2x3 nicht).
- [ ] Weil Matrizen immer von rechts nach links gelesen werden.

> Bei Zahlen ist $2 \cdot 3 = 3 \cdot 2$. Bei Matrizen ändert sich beim Tausch die ganze Zuordnung von Zeilen und Spalten.

# Du willst auf das Element in der **letzten** Zeile und **letzten** Spalte einer Matrix `M` zugreifen. Welcher Code ist am robustesten?
1. [ ] `M[0, 0]`
1. [ ] `M[end, end]`
1. [x] `M[-1, -1]`
1. [ ] `M.last()`

> Negative Indizes sind dein Freund! `-1` bedeutet immer "das Letzte", egal wie groß die Matrix ist.

# Was gibt dieser Code aus?
~~~python
A = np.array([[1, 2], [3, 4]])
v = np.array([10, 20])
# Matrix A (2x2) mal Vektor v (2 Elemente)
print(A @ v)
~~~
1. [ ] `[10, 40]` (Elementweise)
1. [x] `[50, 110]` (Zeile mal Spalte)
1. [ ] `[[10, 20], [30, 40]]`
1. [ ] Error

# Du erhältst den Fehler `ValueError: shapes (2,3) and (2,3) not aligned`. Was ist das Problem?
1. [ ] Die Matrizen enthalten falsche Datentypen.
1. [ ] Du hast `*` statt `@` benutzt.
1. [x] Du versuchst Matrixmultiplikation, aber Spaltenanzahl (3) ungleich Zeilenanzahl (2).
1. [ ] Die Matrizen sind zu groß für den Speicher.

> "Not aligned" ist NumPy-Sprache für: "Der Stecker passt nicht in die Dose". Die inneren Zahlen müssen gleich sein!

# Extrahiere die **zweite Spalte** aus Matrix `M` und multipliziere sie mit 10.
1. `M = np.array([[1, 2], [3, 4]])`
2. `spalte = M[:, 1]`
3. `ergebnis = spalte * 10`
4. `print(ergebnis)`

> Denk an das Slicing `[Zeilen, Spalten]`. Index 1 ist die zweite Spalte.

# Welche Aussage zum Transponieren ist FALSCH?
1. [ ] Aus einer $3 \times 2$ Matrix wird eine $2 \times 3$ Matrix.
1. [ ] Die Werte auf der Hauptdiagonalen bleiben unverändert (bei quadratischen Matrizen).
1. [x] Das Vorzeichen aller Elemente wird umgekehrt (Plus wird Minus).
1. [ ] Es wird technisch mit `A.T` oder `np.transpose(A)` durchgeführt.

> Transponieren ist eine Spiegelung/Drehung, keine Negation. Die Zahlenwerte an sich bleiben gleich, sie wechseln nur den Platz.

# Was passiert hier (Broadcasting)?
~~~python
M = np.array([[10, 10], [20, 20]])
print(M + 1)
~~~
1. [ ] Error, man kann Zahl nicht auf Matrix addieren.
1. [ ] `[11, 11, 21, 21]` (wird zum Vektor)
1. [x] `[[11, 11], [21, 21]]` (Matrix bleibt erhalten)
1. [ ] `[[10, 11], [20, 21]]` (Nur letzte Spalte)

> NumPy ist nett: Wenn du eine einzelne Zahl (`1`) auf eine Matrix addierst, wird sie einfach auf *jedes* Element draufgerechnet.

# Wann sind zwei Vektoren orthogonal?
1. [ ] Wenn ihr Skalarprodukt 1 ist.
1. [ ] Wenn sie in die gleiche Richtung zeigen.
1. [x] Wenn ihr Skalarprodukt 0 ist.
1. [ ] Wenn ihre Länge 0 ist.

> Orthogonal bedeutet "rechtwinklig". Da der Kosinus von 90° Null ist, wird auch das ganze Skalarprodukt Null.

# Berechne das Skalarprodukt (Dot Product) manuell Zeile für Zeile!
1. `a = np.array([1, 2])` und `b = np.array([3, 4])`
2. `p1 = a[0] * b[0]` (Erste Elemente: 1*3)
3. `p2 = a[1] * b[1]` (Zweite Elemente: 2*4)
4. `summe = p1 + p2` (Zusammenzählen: 3+8)

> Das Skalarprodukt ist die Summe der elementweisen Produkte. Erst malnehmen, dann plusrechnen.

# Was ist eine Einheitsmatrix $E$ in Bezug auf die Matrixmultiplikation?
1. [ ] Sie macht alle Werte zu 1.
1. [ ] Sie invertiert das Vorzeichen.
1. [x] Sie ist das neutrale Element ($A \cdot E = A$).
1. [ ] Sie setzt die Matrix auf Null zurück.

> Die Einheitsmatrix ist für Matrizen das, was die Zahl `1` für normale Zahlen ist. Malnehmen ändert nichts.
