# Transformations: If you multiply a matrix $M$ by a vector $v$ ($M \cdot v$), how can you interpret this geometrically?

# Geometry of the determinant: What does it mean geometrically if a $2 \times 2$ transformation matrix has a determinant of `2.0`?
1. [ ] The transformation doubles all angles.
1. [ ] The transformation shifts everything by 2 units.
1. [x] The transformation doubles the area of shapes.
1. [ ] The transformation halves the area.

> The determinant is a scaling factor for areas (in 2D) or volumes (in 3D).

# Order of transformations: You want to first rotate a vector $v$ with matrix $A$ and then scale it with matrix $B$. What is the computation?
1. [ ] $v \cdot A \cdot B$
1. [ ] $A \cdot B \cdot v$
1. [x] $B \cdot (A \cdot v)$ (or $B \cdot A \cdot v$)
1. [ ] $A \cdot (B \cdot v)$

> Matrices "eat" vectors from right to left. The transformation that is closer to the vector ($A$) happens first.

# Code puzzle: Put the lines in the right order to transform a vector `v` with a rotation matrix `R`!
1. `v = np.array([1, 0])`
2. `R = np.array([[0, -1], [1, 0]])` (90 degree rotation)
3. `v_new = R @ v`
4. `print(v_new)`

> First define the objects (vector and matrix), then apply the matrix to the vector (matrix multiplication).

# Inverse transformation: If a matrix $M$ describes a rotation by 30 degrees, what does the inverse $M^{-1}$ do?
1. [ ] It rotates by another 30 degrees.
1. [ ] It sets everything to zero.
1. [x] It rotates back by 30 degrees (in the opposite direction).
1. [ ] It reflects the vector.

> The inverse undoes exactly what the original matrix did.

# Visualization: Which `matplotlib` function is best suited for drawing vectors as arrows?
1. [ ] `plt.plot()`
1. [ ] `plt.scatter()`
1. [x] `plt.quiver()`
1. [ ] `plt.bar()`

> `plot` draws lines, `scatter` draws points. For vectors (direction + length) there is a special function (a quiver is a container for arrows).

# Understanding: A matrix is "singular" (determinant 0). What does this mean for the transformation?
- [x] The transformation "loses" dimensions (e.g. an area becomes a line or a point).
- [ ] The transformation is invertible.
- [x] There is no inverse matrix.
- [ ] The transformation makes the area infinitely large.

> If an area is "squashed" into a line, this step can no longer be undone uniquely (information is lost).

# Python refresher: What does `np.radians(180)` do?
1. [ ] Computes the radius of a circle.
1. [x] Converts 180 degrees to radians ($\pi$).
1. [ ] Converts radians to degrees.
1. [ ] Draws a circle.

> NumPy's trigonometric functions (like `sin`, `cos`) almost always expect radians, not degrees!

# Code comprehension: What happens here?

# Origin: Where is the zero vector $(0,0)$ mapped by a linear transformation (matrix multiplication)?

1. [x] Always to the zero vector $(0,0)$.
1. [ ] To $(1,1)$.
1. [ ] That is not defined.

> No matter how you rotate or stretch space: the center (origin) stays where it is ($M \cdot 0 = 0$).

# Refresher (chapter 3): What happens if the dimensions in `M @ v` do not match (e.g. 3x3 matrix times 2D vector)?
1. [ ] NumPy fills missing values with 0.
1. [ ] NumPy cuts off the matrix.
1. [x] NumPy raises a `ValueError` (shapes not aligned).
1. [ ] The dot product is computed.

> Transformations only work if the vector has as many dimensions as the matrix has "inputs" (columns).

# Code puzzle: How do you create an identity matrix that serves as a "neutral transformation" (does nothing)?
1. `dim = 3`
2. `I = np.eye(dim)`
3. `v = np.array([1, 2, 3])`
4. `print(I @ v)` (the result is v again)

> The identity matrix is the "times one" of the matrix world.
