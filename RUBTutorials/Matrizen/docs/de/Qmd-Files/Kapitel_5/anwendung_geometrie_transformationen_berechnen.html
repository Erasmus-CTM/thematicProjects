## Skalierung 2D
```{pyodide-python}
import numpy as np
import matplotlib.pyplot as plt

A = np.array([
    [1, 1],
    [3, 1],
    [2, 3]
])

def skalierung_2d(matrix, s_2d_x, s_2d_y):
    skalierungsmatrix = np.array([
        [s_2d_x, 0],
        [0, s_2d_y]
    ])
    return matrix @ skalierungsmatrix

skalierte_matrix = skalierung_2d(A, 2, 0.5)
print("Originale Punkte:\n", A)
print("\nSkalierte Punkte:\n", skalierte_matrix)
```
<details>
<summary> Kurze Code Erklärung </summary>

* Zuerst wird eine Matrix wie gewohnt definiert, welche unsere Form darstellt durch die einzelnen Punktkoordinaten
* Danach wird eine Funktion definiert, in der zuerst die passende Matrix ausgewählt werden kann, die man skalieren will (es kann ja mehr als eine definiert sein) und dann die Skalierung in Richtung X- und Y-Achse bestimmt wird.
* Zuletzt wird die Funktion ausgeführt und ausgegeben.
</details>

## Verschiebung in 2D
```{pyodide-python}
def verschiebung_2d(matrix, v_x, v_y):
    verschiebungsvektor = np.array([v_x, v_y])
    return matrix + verschiebungsvektor

verschobene_matrix = verschiebung_2d(A, 3, 5)
print("Originale Punkte:\n", A)
print("\nVerschobene Punkte:\n", verschobene_matrix)
```
<details>
<summary> Kurze Code Erklärung </summary>

*   Anders als bei den anderen Transformationen wird hier **keine Matrixmultiplikation**, sondern eine **Vektoraddition** verwendet.
*   Die Funktion `verschiebung_2d` nimmt die Punkte und die Verschiebungswerte für x und y entgegen.
*   Der Verschiebungsvektor wird zu jeder Zeile (also zu jedem Punkt) der Matrix `A` addiert. NumPy führt dies dank "Broadcasting" automatisch korrekt aus.
</details>

## Rotation in 2D
```{pyodide-python}
def rotation_2d(matrix, winkel_grad):
    # Umrechnung von Grad in Radiant, da np.cos/sin Radiant erwarten
    winkel_rad = np.radians(winkel_grad)
    c, s = np.cos(winkel_rad), np.sin(winkel_rad)
    rotationsmatrix = np.array([
        [c, -s],
        [s,  c]
    ])
    # Wichtig: Die Rotationsmatrix wird von links angewendet
    return (rotationsmatrix @ matrix.T).T

rotierte_matrix = rotation_2d(A, 90)
print("Originale Punkte:\n", A)
print("\nUm 90 Grad rotierte Punkte:\n", rotierte_matrix)
```
<details>
<summary> Kurze Code Erklärung </summary>

*   Die Funktion `rotation_2d` nimmt einen Winkel in Grad entgegen und rechnet ihn in Radiant um, da die trigonometrischen Funktionen in NumPy dies erwarten.
*   Sie erstellt die 2D-Rotationsmatrix.
*   **Wichtig:** Bei der Multiplikation muss die Transformationsmatrix von links an die Punktvektoren multipliziert werden ($P' = M \cdot P$). Da unsere Punkte als Zeilen in der Matrix `A` stehen, müssen wir `A` zuerst transponieren (`A.T`), die Multiplikation durchführen und das Ergebnis zurück transponieren (`.T`). Gleichwertig und kürzer ist `A @ M.T`.
</details>

## Spiegelung in 2D
```{pyodide-python}
def spiegelung_2d_y_achse(matrix):
    spiegelungsmatrix = np.array([
        [-1, 0],
        [0, 1]
    ])
    return matrix @ spiegelungsmatrix

gespiegelte_matrix = spiegelung_2d_y_achse(A)
print("Originale Punkte:\n", A)
print("\nAn der y-Achse gespiegelte Punkte:\n", gespiegelte_matrix)
```
<details>
<summary> Kurze Code Erklärung </summary>

*   Die Funktion `spiegelung_2d_y_achse` erstellt die entsprechende Spiegelungsmatrix.
*   Diese wird von rechts an die Punktmatrix `A` multipliziert (`A @ M`), um die x-Koordinaten aller Punkte zu negieren.
*   Eigentlich müsste es wie bei der Rotation `A @ M.T` heißen. Weil Spiegelungs- und Skalierungsmatrizen hier symmetrisch sind ($M^T = M$), ist das dasselbe wie `A @ M`. Bei einer Rotationsmatrix gilt das **nicht**: `A @ R` würde in die Gegenrichtung drehen.

</details>

## Scaling 2D
```{pyodide-python}
import numpy as np

```
<details>
<summary> Short code explanation </summary>

* First, a matrix is defined as usual; it represents our shape through the individual point coordinates.
* Then a function is defined in which you first pass the matrix you want to scale (there may be more than one defined) and then set the scaling in the x and y directions.
* Finally, the function is called and the result is printed.
</details>

## Translation in 2D
```{pyodide-python}
def translation_2d(matrix, v_x, v_y):
    translation_vector = np.array([v_x, v_y])
    return matrix + translation_vector

shifted_matrix = translation_2d(A, 3, 5)
print("Original points:\n", A)
print("\nShifted points:\n", shifted_matrix)
```
<details>
<summary> Short code explanation </summary>

*   Unlike the other transformations, **no matrix multiplication** is used here, but a **vector addition**.
*   The function `translation_2d` takes the points and the translation values for x and y.
*   The translation vector is added to every row (i.e. every point) of the matrix `A`. Thanks to "broadcasting", NumPy does this correctly and automatically.
</details>

## Rotation in 2D
```{pyodide-python}
def rotation_2d(matrix, angle_deg):
    # Convert degrees to radians, since np.cos/sin expect radians
    angle_rad = np.radians(angle_deg)
    c, s = np.cos(angle_rad), np.sin(angle_rad)
    rotation_matrix = np.array([
        [c, -s],
        [s,  c]
    ])
    # Important: the rotation matrix is applied from the left
    return (rotation_matrix @ matrix.T).T

rotated_matrix = rotation_2d(A, 90)
print("Original points:\n", A)
print("\nPoints rotated by 90 degrees:\n", rotated_matrix)
```
<details>
<summary> Short code explanation </summary>

*   The function `rotation_2d` takes an angle in degrees and converts it to radians, since the trigonometric functions in NumPy expect that.
*   It creates the 2D rotation matrix.
*   **Important:** In the multiplication, the transformation matrix must be multiplied onto the point vectors from the left ($P' = M \cdot P$). Since our points are the rows of the matrix `A`, we first have to transpose `A` (`A.T`), carry out the multiplication and transpose the result back (`.T`).
</details>

## Reflection in 2D
```{pyodide-python}
def reflection_2d_y_axis(matrix):
    reflection_matrix = np.array([
        [-1, 0],
        [0, 1]
    ])
    return matrix @ reflection_matrix

reflected_matrix = reflection_2d_y_axis(A)
print("Original points:\n", A)
print("\nPoints reflected across the y-axis:\n", reflected_matrix)
```
<details>
<summary> Short code explanation </summary>

*   The function `reflection_2d_y_axis` creates the corresponding reflection matrix.
*   It is multiplied onto the point matrix `A` from the right (`A @ M`) to negate the x-coordinates of all points.
*   Strictly speaking, as with the rotation, it would have to be `A @ M.T`. Because the reflection and scaling matrices here are symmetric ($M^T = M$), this is the same as `A @ M`. For a rotation matrix this does **not** hold: `A @ R` would rotate in the opposite direction.

</details>
