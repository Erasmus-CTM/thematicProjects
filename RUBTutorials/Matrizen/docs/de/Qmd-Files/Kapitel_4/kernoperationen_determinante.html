Die Determinante ist ein Skalarwert, welcher aus einer quadratischen Matrix bestimmt wird. Mithilfe dessen können viele Aussagen über eine Matrix, beziehungsweise die zugrundeliegende Funktion getroffen werden.

4.2.1. Definition

Die Determinante einer quadratischen Matrix \(A\), geschrieben als \(\det(A)\) oder \(|A|\), ist ein Skalarwert, der aus den Elementen der Matrix berechnet wird.

  • Geometrische Bedeutung: Die Determinante beschreibt, wie sich das Volumen (oder die Fläche im 2D-Raum) durch die lineare Transformation, die durch die Matrix dargestellt wird, verändert.
    • \(|\det(A)| > 1\): Das Volumen wird gestreckt.
    • \(|\det(A)| < 1\): Das Volumen wird gestaucht.
    • \(\det(A) = 0\): Das Volumen kollabiert zu einer niedrigeren Dimension (zum Beispiel eine Fläche zu einer Linie). Dies bedeutet, dass die Spaltenvektoren der Matrix linear abhängig sind (siehe 4.1) und der Rang der Matrix kleiner als die Anzahl ihrer Spalten ist.
  • Algebraische Bedeutung: Eine Matrix ist genau dann invertierbar, wenn ihre Determinante ungleich Null ist.

Für eine \(2 \times 2\)-Matrix lässt sich die Determinante noch gut von Hand berechnen: Hauptdiagonale mal Hauptdiagonale minus Nebendiagonale mal Nebendiagonale. \[ \det\begin{pmatrix} a & b \\ c & d \end{pmatrix} = a \cdot d - b \cdot c \]

Determinanten von Hand
\(\det\begin{pmatrix} 4 & 7 \\ 2 & 6 \end{pmatrix} =\)

\(\det\begin{pmatrix} 3 & 1 \\ 6 & 2 \end{pmatrix} =\)

\(\det\begin{pmatrix} 2 & 0 & 0 \\ 0 & 3 & 0 \\ 0 & 0 & -1 \end{pmatrix} =\)

Die zweite Matrix ist also nicht invertierbar, ihre zweite Zeile ist das Doppelte der ersten. Bei einer Diagonalmatrix ist die Determinante einfach das Produkt der Diagonaleinträge.

## 4.2.1. Definition

Die **Determinante** einer quadratischen Matrix $A$, geschrieben als $\det(A)$ oder $|A|$, ist ein Skalarwert, der aus den Elementen der Matrix berechnet wird.

*   **Geometrische Bedeutung:** Die Determinante beschreibt, wie sich das Volumen (oder die Fläche im 2D-Raum) durch die lineare Transformation, die durch die Matrix dargestellt wird, verändert.
    *   $|\det(A)| > 1$: Das Volumen wird gestreckt.
    *   $|\det(A)| < 1$: Das Volumen wird gestaucht.

Für eine $2 \times 2$-Matrix lässt sich die Determinante noch gut von Hand berechnen: Hauptdiagonale mal Hauptdiagonale minus Nebendiagonale mal Nebendiagonale.
$$
\det\begin{pmatrix} a & b \\ c & d \end{pmatrix} = a \cdot d - b \cdot c
$$


## 4.2.2. Determinante in NumPy berechnen

Die Berechnung der Determinante von Hand ist für Matrizen größer als 3x3 sehr aufwendig. Mithilfe der `numpy`-Funktion `np.linalg.det()` ist es jedoch sehr einfach.

```{pyodide-python}
#| read-only: true
import numpy as np

# Eine 2x2 Matrix
A = np.array([[4, 7],
              [2, 6]])

# Eine 3x3 Matrix, deren Determinante 0 ist
# (Die 3. Zeile ist die Summe der ersten beiden)
B = np.array([[1, 0, 1],
              [2, 1, 1],
              [3, 1, 2]])

det_A = np.linalg.det(A)
det_B = np.linalg.det(B)

print(f"Matrix A:\n{A}")
print(f"Determinante von A: {det_A}") # 4*6 - 7*2 = 24 - 14 = 10

print(f"Gerundetes Ergebnis det(A): {det_A:.1f}") 
#:.1f rundet auf die erste Nachkommastelle

print(f"Determinante von B: {det_B}")  # mathematisch genau 0
```
Beachte, dass das Ergebnis für `det_B` aufgrund von Fließkomma-Ungenauigkeiten nicht exakt `0.0` ist, aber sehr nah dran. Hier ein Beispiel, an dem du das erkennen kannst.

The determinant is a scalar value that is computed from a square matrix. With it, many statements can be made about a matrix, or about the underlying function.

## 4.2.1. Definition {#definition}

The **determinant** of a square matrix $A$, written as $\det(A)$ or $|A|$, is a scalar value that is computed from the elements of the matrix.

*   **Geometric meaning:** The determinant describes how the volume (or the area in 2D space) changes under the linear transformation represented by the matrix.
    *   $|\det(A)| > 1$: The volume is stretched.
    *   $|\det(A)| < 1$: The volume is compressed.
    *   $\det(A) = 0$: The volume collapses to a lower dimension (for example an area to a line). This means that the column vectors of the matrix are linearly dependent (see [4.1](kernoperationen_rang.qmd)) and the rank of the matrix is smaller than the number of its columns.

*   **Algebraic meaning:** A matrix is **invertible** if and only if its determinant is **non-zero**.

For a $2 \times 2$ matrix, the determinant can still easily be computed by hand: main diagonal times main diagonal minus off-diagonal times off-diagonal.
$$
\det\begin{pmatrix} a & b \\ c & d \end{pmatrix} = a \cdot d - b \cdot c
$$

```{math-exercise}
#| label: determinante-hand-en
#| caption: Determinants by hand
#| partial-credit: true
$\det\begin{pmatrix} 4 & 7 \\ 2 & 6 \end{pmatrix} =$ _[10]

$\det\begin{pmatrix} 3 & 1 \\ 6 & 2 \end{pmatrix} =$ _[0]

$\det\begin{pmatrix} 2 & 0 & 0 \\ 0 & 3 & 0 \\ 0 & 0 & -1 \end{pmatrix} =$ _[-6]
```

So the second matrix is **not** invertible; its second row is twice the first. For a diagonal matrix, the determinant is simply the product of the diagonal entries.

## 4.2.2. Computing the determinant in NumPy {#determinante-in-numpy-berechnen}

Computing the determinant by hand is very laborious for matrices larger than 3x3. With the `numpy` function `np.linalg.det()`, however, it is very easy.

```{pyodide-python}
#| read-only: true
import numpy as np

# A 2x2 matrix
A = np.array([[4, 7],
              [2, 6]])

# A 3x3 matrix whose determinant is 0
# (the 3rd row is the sum of the first two)
B = np.array([[1, 0, 1],
              [2, 1, 1],
              [3, 1, 2]])

det_A = np.linalg.det(A)
det_B = np.linalg.det(B)

print(f"Matrix A:\n{A}")
print(f"Determinant of A: {det_A}") # 4*6 - 7*2 = 24 - 14 = 10

print(f"Rounded result det(A): {det_A:.1f}") 
#:.1f rounds to the first decimal place

print(f"Determinant of B: {det_B}")  # mathematically exactly 0
```
Note that the result for `det_B` is not exactly `0.0` due to floating-point inaccuracies, but very close to it. Here is an example where you can see this.
