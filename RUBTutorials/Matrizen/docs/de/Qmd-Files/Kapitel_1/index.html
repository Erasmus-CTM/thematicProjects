```quizdown
# Was beschreibt ein Vektor $\vec{v} = (3, 4)$ anschaulich?

# Was berechnet `np.linalg.norm(v)`?
1. [ ] Das Skalarprodukt von `v` mit sich selbst.
1. [x] Die Länge (Norm) des Vektors `v`.
1. [ ] Den Winkel von `v` zur x-Achse.
1. [ ] Die Anzahl der Elemente in `v`.

# Wann ist das Skalarprodukt zweier Vektoren gleich 0?
1. [ ] Wenn beide Vektoren gleich lang sind.
```

```quizdown
# What does a vector $\vec{v} = (3, 4)$ intuitively represent?
1. [ ] A single point in space.
1. [x] A displacement/arrow from the origin to the point (3, 4).
1. [ ] An area.
1. [ ] A number without direction.

> A vector has direction and length, not a fixed position — it describes a displacement.

# What does `np.linalg.norm(v)` compute?
1. [ ] The dot product of `v` with itself.
1. [x] The length (norm) of the vector `v`.
1. [ ] The angle of `v` relative to the x-axis.
1. [ ] The number of elements in `v`.

> `norm()` returns the length/magnitude of a vector — geometrically the distance from the origin to its endpoint.

# When is the dot product of two vectors equal to 0?
1. [ ] When both vectors have the same length.
1. [x] When the vectors are orthogonal (perpendicular) to each other.
1. [ ] When both vectors point in the same direction.
1. [ ] Never, the dot product is always positive.

> The cosine of 90° is 0, so the entire dot product becomes 0 when the vectors are perpendicular to each other.

# What is the difference between element-wise multiplication and the dot product?
1. [ ] There is no difference.
1. [x] Element-wise multiplication produces another vector, the dot product produces a single number.
1. [ ] Element-wise multiplication only works for square matrices.
1. [ ] The dot product only exists for 2D vectors.

> `a * b` (element-wise) produces a new vector of the same length; `a @ b` or `np.dot(a, b)` produces a single number.
```
