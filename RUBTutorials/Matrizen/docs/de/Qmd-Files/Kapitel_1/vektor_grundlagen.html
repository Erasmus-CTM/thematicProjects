1.1.2. Was sind Vektoren?

Ein Vektor ist ein mathematisches Objekt, das eine Richtung und eine Länge (Betrag) besitzt. Anschaulich lässt sich ein Vektor als Pfeil im Raum interpretieren: Er beginnt an einem Punkt (häufig dem Ursprung) und zeigt auf einen anderen Punkt.

Anders als Punkte haben Vektoren keine feste Position – sie beschreiben nur eine Verschiebung. Deshalb spricht man auch von einem “Ortsvektor”, wenn man den Vektor vom Ursprung zu einem Punkt betrachtet.

1.1.2.1. Schreibweise

Vektoren können unterschiedlich notiert werden:

  • Als Spaltenvektor:

    \[ \begin{pmatrix} 2 \\ 3 \end{pmatrix} \]

  • Oder als Zeilenvektor:

    \[ (2, 3) \]

Mengenklammern wie \(\{2, 3\}\) eignen sich dagegen nicht für Vektoren: Bei Mengen spielt die Reihenfolge keine Rolle (\(\{2, 3\} = \{3, 2\}\)), bei Vektoren schon (\((2, 3) \neq (3, 2)\)).

Je nach Kontext ist eine andere Darstellung sinnvoll. In Python verwenden wir meist die „Zeilenform” – als Liste oder Array.

1.1.2.2. Beispiele

  • Ein Vektor \(\vec{v} = (3, 4)\) beschreibt eine Bewegung um 3 Einheiten nach rechts und 4 Einheiten nach oben.
  • Der Vektor \((0, -5)\) zeigt 5 Einheiten nach unten.

Solche Vektoren sind nicht nur in der Mathematik nützlich – auch in Physik, Informatik und maschinellem Lernen spielen sie eine zentrale Rolle.

1.1.3. Vektoren in Python

In Python nutzen wir die Bibliothek numpy, um Vektoren darzustellen. Dabei verwenden wir meist Arrays, die ähnlich wie Listen funktionieren, aber besser für mathematische Rechnungen optimiert sind.

1.1.3.1. NumPy Arrays als Vektoren

Python kennt keine eingebauten Vektoren – aber die Bibliothek NumPy bietet ein sehr leistungsfähiges Werkzeug: das array.

Du kannst dir so einen Vektor auch als Pfeil vom Ursprung \((0,0)\) zum Punkt \((2,3)\) vorstellen.

1.1.3.2. Dimension und Form von Vektoren prüfen

Wenn du mit Vektoren arbeitest, ist es wichtig, ihre Dimension (also wie viele Achsen sie haben) und ihre Form (also die genaue Struktur) zu kennen. Das hilft dir, Fehler zu vermeiden – besonders bei späteren Berechnungen wie dem Skalarprodukt oder bei Matrizenmultiplikationen.

In NumPy gibt es dafür ein paar hilfreiche Attribute:

  • .ndim → Anzahl der Dimensionen (z. B. 1D, 2D)
  • .shape → Form des Arrays (z. B. (3,) für drei Einträge in einem Vektor)
  • .size → Gesamtanzahl der Elemente
HinweisEine Erklärung der Vektor- Dimensionen in numpy

Erklärung zum Verständnis von Vektor-Dimensionen in numpy

  • Ein Vektor in NumPy ist ein Array, dessen Dimension (Anzahl der Achsen) bestimmt, ob es ein 1D- oder 2D-Vektor ist.
  • 1D-Vektor:
    • Hat genau eine Achse (z.B. shape = (3,))
    • Wird meist als einfache Liste von Zahlen dargestellt, z.B. [1, 2, 3]
    • Enthält nur eine Reihe von Werten ohne zusätzliche Struktur.
  • 2D-Vektor:
    • Hat zwei Achsen (z.B. shape = (1, 3) oder (3, 1))
    • Ist eine Matrix mit entweder einer Zeile und mehreren Spalten (Zeilenvektor) oder einer Spalte und mehreren Zeilen (Spaltenvektor)
    • Wird genutzt, wenn die Vektoren als Matrizen für lineare Algebra oder als Daten in bestimmten Formaten gebraucht werden.
  • Auch wenn alle Beispiele die gleiche Anzahl an Einträgen haben (z.B. 3), unterscheidet sich die Struktur durch die Dimension des Arrays.
  • Das Verständnis der Dimension ist wichtig, da viele Operationen in NumPy (z.B. Matrixmultiplikation) davon abhängen.

## Funktionen

Bisher haben wir Code geschrieben, der von oben nach unten ausgeführt wird. Eine Funktion wird mit dem Schlüsselwort `def` definiert, gefolgt von einem Namen und Klammern `()`. Innerhalb der Klammern können **Parameter** (Eingabewerte) übergeben werden. Mit `return` gibt die Funktion ein Ergebnis zurück.

## Schleifen

Zum Verständnis ein paar Beispiele und eine Aufgabe dazu:

`For-Schleifen` wiederholen sich über ein bestimmtes Intervall. Das Schlüsselwort `range` beschreibt hierbei das Intervall von $a$ bis $b$. Dabei ist $a$ der Start der Iteration, $b$ selbst gehört **nicht** mehr dazu: `range(5, 20)` läuft von 5 bis 19.

```{pyodide-python}
a = 5 #Die Variable a wird hier definiert
b = 20
for i in range(a,b,2): #a,b sind die Grenzen 2 die Schrittgröße
    print(i+1)
```

Wenn eine Rechnung/ eine Abfrage mehrfach ausgeführt werden soll, ist dies vereinfacht mit Hilfe von Schleifen möglich.
`While-Schleifen`wiederholen hierbei den Code solange, eine gewisse Bedingung erfüllt ist.
Ein kleines Beispiel:
```{pyodide-python}
a = 3 #Die Variable a wird hier definiert
b = 11
while a<b:
    a = a+1 #ist sehr wichtig, da die Bedingung sonst immer erfüllt bliebe, heißt es wäre eine ENDLOS-Schleife
    print(a)
```

## 1.1.2. Was sind Vektoren?

Ein Vektor ist ein mathematisches Objekt, das eine Richtung und eine Länge (Betrag) besitzt. Anschaulich lässt sich ein Vektor als Pfeil im Raum interpretieren:
Er beginnt an einem Punkt (häufig dem Ursprung) und zeigt auf einen anderen Punkt.

Anders als Punkte haben Vektoren **keine feste Position** – sie beschreiben nur eine Verschiebung. Deshalb spricht man auch von einem "Ortsvektor", wenn man den Vektor vom Ursprung zu einem Punkt betrachtet.

### 1.1.2.1. Schreibweise

Vektoren können unterschiedlich notiert werden:

- **Als Spaltenvektor**:

  $$
  \begin{pmatrix}
  2 \\
  3
  \end{pmatrix}
  $$

- **Oder als Zeilenvektor**:

  $$
  (2, 3)
  $$

Mengenklammern wie $\{2, 3\}$ eignen sich dagegen **nicht** für Vektoren: Bei Mengen spielt die Reihenfolge keine Rolle ($\{2, 3\} = \{3, 2\}$), bei Vektoren schon ($(2, 3) \neq (3, 2)$).

Je nach Kontext ist eine andere Darstellung sinnvoll. In Python verwenden wir meist die „Zeilenform" – als Liste oder Array.

### 1.1.2.2. Beispiele

- Ein Vektor $\vec{v} = (3, 4)$ beschreibt eine Bewegung um 3 Einheiten nach rechts und 4 Einheiten nach oben.
- Der Vektor $(0, -5)$ zeigt 5 Einheiten nach unten.

Solche Vektoren sind nicht nur in der Mathematik nützlich – auch in Physik, Informatik und maschinellem Lernen spielen sie eine zentrale Rolle.

***

## 1.1.3. Vektoren in Python

In Python nutzen wir die Bibliothek `numpy`, um Vektoren darzustellen.
Dabei verwenden wir meist **Arrays**, die ähnlich wie Listen funktionieren, aber besser für mathematische Rechnungen optimiert sind.

### 1.1.3.1. NumPy Arrays als Vektoren

Python kennt keine eingebauten Vektoren – aber die Bibliothek `NumPy` bietet ein sehr leistungsfähiges Werkzeug: das `array`.

```{pyodide-python}
import numpy as np

v = np.array([2, 3])
print(v)
```

Du kannst dir so einen Vektor auch als Pfeil vom Ursprung $(0,0)$ zum Punkt $(2,3)$ vorstellen.

### 1.1.3.2. Dimension und Form von Vektoren prüfen

Wenn du mit Vektoren arbeitest, ist es wichtig, ihre Dimension (also wie viele Achsen sie haben) und ihre Form (also die genaue Struktur) zu kennen. Das hilft dir, Fehler zu vermeiden – besonders bei späteren Berechnungen wie dem Skalarprodukt oder bei Matrizenmultiplikationen.

In NumPy gibt es dafür ein paar hilfreiche Attribute:

- `.ndim` → Anzahl der Dimensionen (z. B. 1D, 2D)
- `.shape` → Form des Arrays (z. B. (3,) für drei Einträge in einem Vektor)
- `.size` → Gesamtanzahl der Elemente

```{pyodide-python}
# Ein 1D-Vektor (Zeilenform)
v1 = np.array([4, 5, 6])
print("v1:", v1)
print("Dimension (ndim):", v1.ndim)
print("Form (shape):", v1.shape)
print("Größe (size):", v1.size)

print()
# Ein 2D-Vektor als Spaltenvektor
v2 = np.array([[4], [5], [6]])
print("v2:\n", v2)
print("Dimension (ndim):", v2.ndim)
print("Form (shape):", v2.shape)
print("Größe (size):", v2.size)

print()
# Ein 2D-Vektor als Zeilenvektor
v3 = np.array([[4, 5, 6]])
print("v3:\n", v3)
print("Dimension (ndim):", v3.ndim)
print("Form (shape):", v3.shape)
print("Größe (size):", v3.size)
```

:::{.callout-note title="Eine Erklärung der Vektor- Dimensionen in `numpy`" collapse="true"}

**Erklärung zum Verständnis von Vektor-Dimensionen in `numpy`**

- Ein Vektor in NumPy ist ein Array, dessen Dimension (Anzahl der Achsen) bestimmt, ob es ein 1D- oder 2D-Vektor ist.
- **1D-Vektor:**
  - Hat genau eine Achse (z.B. `shape = (3,)`)
  - Wird meist als einfache Liste von Zahlen dargestellt, z.B. `[1, 2, 3]`
  - Enthält nur eine Reihe von Werten ohne zusätzliche Struktur.
- **2D-Vektor:**
  - Hat zwei Achsen (z.B. `shape = (1, 3)` oder `(3, 1)`)
  - Ist eine Matrix mit entweder einer Zeile und mehreren Spalten (Zeilenvektor) oder einer Spalte und mehreren Zeilen (Spaltenvektor)
  - Wird genutzt, wenn die Vektoren als Matrizen für lineare Algebra oder als Daten in bestimmten Formaten gebraucht werden.
- Auch wenn alle Beispiele die gleiche Anzahl an Einträgen haben (z.B. 3), unterscheidet sich die Struktur durch die Dimension des Arrays.
- Das Verständnis der Dimension ist wichtig, da viele Operationen in NumPy (z.B. Matrixmultiplikation) davon abhängen.

## Variables

For an easy introduction to Python, we will first look at variables. It is worth highlighting the difference from variables in mathematics. Here is a brief example:

```{pyodide-python}
#| read-only: true
a = 7
print(a)
```
This is a variable assignment. Variables can be used for calculations after they have been assigned. You can see a few examples in the following code:

```{pyodide-python}
#| read-only: true
a = 4
b = 5
print(a+b)
print(a*b)
print(a/2)
print(a-b)
```
Multiplication in Python uses an asterisk *. Division in Python uses the forward slash /.
The following example illustrates the difference from variables in mathematics:

```{pyodide-python}
#| read-only: true
a = 4
a = 7 + a
b = 5
print(a+b)
print(a*b)
print(a/2)
print(a-b)
```

As you can see, variables can change or be reassigned. In Python, a variable always holds the value that was most recently assigned to it.

Instead of individual statements, let us now look at a complete program. Imagine we are driving a longer route by car and note down the odometer reading at the beginning of the trip, at certain points during the journey, along with the elapsed driving time.
We can use this information to calculate the average speed for the entire trip as well as for the individual intervals.
A simple Python program that does this for us is the following:


```{pyodide-python}
#| read-only: true
# Program to calculate average speed
s0 = 13157.6 # Odometer reading at the start
s1 = 13160.0 # Odometer reading at 1st measurement
t1 = 4 # Minutes from trip start at 1st measurement
s2 = 13177.4 # Odometer reading at 2nd measurement
t2 = 16 # Minutes from trip start at 2nd measurement
s3 = 13267.4 # Odometer reading at 3rd measurement
t3 = 64 # Minutes from trip start at 3rd measurement
# Average speed in km/h for the ...
v1 = (s1 - s0) / (t1 / 60) # ... 1st interval
v2 = (s2 - s1) / ((t2 - t1) / 60) # ... 2nd interval
v3 = (s3 - s2) / ((t3 - t2) / 60) # ... 3rd interval
v_average = (s3 - s0) / (t3 / 60) # Overall
print(v1)
print(v2)
print(v3)
print("Average: {} km/h".format(v_average))
```

This example also shows that variables can have more than one letter.
In Python, variables can also be defined using whole words, which is also sensible for making the code easier to understand with meaningful variable names.

## Conditional Statements

A conditional statement allows you to distinguish between two or more cases.
Translated, this means: If "x", do "y", otherwise do "z". Consider the following example:

```{pyodide-python}
#| read-only: true
a = 15
b = 20
if a>=b:
    print("a is greater than or equal to b")
else:
    print("b is greater than a")
```

If you want to distinguish more than two cases, you can use "elif" between "if" and "else". This is short for "else if". Consider the following code:

```{pyodide-python}
#| read-only: true
a = 25
b = 20
if a==b:
    print("a is equal to b")
elif a>b:
    print("a is greater than b")
else:
    print("b is greater than a")
```

It is not necessary to always use if and else. You can also use only if when you do not want to do anything in the else case. ## Functions

Until now we have written code that runs from top to bottom. If we wanted to repeat a calculation, such as computing a factorial or an average speed, at different places with different values, we would have to copy and paste the code. This is messy and error-prone.

**Functions** solve this problem. A function is a named, reusable block of code that performs a specific task. You define it once and can then "call" it as many times as you like.

A function is defined with the keyword `def`, followed by a name and parentheses `()`. **Parameters** (input values) can be passed inside the parentheses. The function returns a result using `return`.

### f-Strings in Python
In the following we use so-called **f-strings** for `print()` output. An f-string is introduced by an `f` before the opening quotation mark (e.g. `f"Hello"`).

The big advantage is that you can embed variables and expressions directly into the text by placing them inside curly braces `{}`. This often makes the code much more readable.
```{pyodide-python}
#| read-only: true
# Definition of a simple function that adds two numbers
def add(number1, number2):
    total = number1 + number2
    return total

# Calling the function with the values 5 and 10
print(f"The result of 5 + 10 is: {add(5, 10)}")

# Calling it again with different values
print(f"The result of -2 + 7 is: {add(-2, 7)}")
```

## Loops

For understanding, here are some examples and an exercise:

`For loops` repeat over a certain range. The keyword `range` describes the range from $a$ to $b$. Here $a$ is the start of the iteration; $b$ itself is **not** included: `range(5, 20)` runs from 5 to 19.

```{pyodide-python}
a = 5 #The variable a is defined here
b = 20
for i in range(a,b,2): #a,b are the bounds, 2 is the step size
    print(i+1)
```

If a calculation or query needs to be executed multiple times, this is made easy with loops.
`While loops` repeat the code for as long as a certain condition is met.
A brief example:
```{pyodide-python}
a = 3 #The variable a is defined here
b = 11
while a<b:
    a = a+1 #very important — otherwise the condition would always stay true, resulting in an INFINITE loop
    print(a)
```

## 1.1.2. What are Vectors? {#was-sind-vektoren}

A vector is a mathematical object that has a direction and a magnitude (length). Intuitively, a vector can be interpreted as an arrow in space:
It starts at one point (often the origin) and points to another.

Unlike points, vectors have **no fixed position** — they describe only a displacement. This is why the term "position vector" is used when considering the vector from the origin to a specific point.

### 1.1.2.1. Notation

Vectors can be written in different ways:

- **As a column vector**:

  $$
  \begin{pmatrix}
  2 \\
  3
  \end{pmatrix}
  $$

- **Or as a row vector**:

  $$
  (2, 3)
  $$

Set braces like $\{2, 3\}$, on the other hand, are **not** suitable for vectors: for sets the order does not matter ($\{2, 3\} = \{3, 2\}$), for vectors it does ($(2, 3) \neq (3, 2)$).

Depending on the context, a different representation makes sense. In Python, we mostly use the "row form" — as a list or array.

### 1.1.2.2. Examples

- A vector $\vec{v} = (3, 4)$ describes a movement of 3 units to the right and 4 units upward.
- The vector $(0, -5)$ points 5 units downward.

Such vectors are not only useful in mathematics — they also play a central role in physics, computer science, and machine learning.

***

## 1.1.3. Vectors in Python {#vektoren-in-python}

In Python, we use the `numpy` library to represent vectors.
We primarily use **arrays**, which work similarly to lists but are better optimised for mathematical calculations.

### 1.1.3.1. NumPy Arrays as Vectors

Python has no built-in vectors — but the `NumPy` library provides a very powerful tool: the `array`.

```{pyodide-python}
import numpy as np
# A vector with two entries
v = np.array([2, 3])
print(v)
```

You can think of such a vector as an arrow from the origin $(0,0)$ to the point $(2,3)$.

### 1.1.3.2. Checking the Dimension and Shape of Vectors

When working with vectors, it is important to know their dimension (how many axes they have) and their shape (the exact structure). This helps you avoid errors — especially in later calculations such as the dot product or matrix multiplication.

NumPy provides a few helpful attributes for this:

- `.ndim` → Number of dimensions (e.g. 1D, 2D)
- `.shape` → Shape of the array (e.g. (3,) for three entries in a vector)
- `.size` → Total number of elements

```{pyodide-python}
# A 1D vector (row form)
v1 = np.array([4, 5, 6])
print("v1:", v1)
print("Dimensions (ndim):", v1.ndim)
print("Shape:", v1.shape)
print("Size:", v1.size)

print()
# A 2D vector as a column vector
v2 = np.array([[4], [5], [6]])
print("v2:\n", v2)
print("Dimensions (ndim):", v2.ndim)
print("Shape:", v2.shape)
print("Size:", v2.size)

print()
# A 2D vector as a row vector
v3 = np.array([[4, 5, 6]])
print("v3:\n", v3)
print("Dimensions (ndim):", v3.ndim)
print("Shape:", v3.shape)
print("Size:", v3.size)
```

:::{.callout-note title="An Explanation of Vector Dimensions in `numpy`" collapse="true"}

**Explanation for Understanding Vector Dimensions in `numpy`**

- A vector in NumPy is an array whose dimension (number of axes) determines whether it is a 1D or 2D vector.
- **1D vector:**
  - Has exactly one axis (e.g. `shape = (3,)`)
  - Is typically represented as a simple list of numbers, e.g. `[1, 2, 3]`
  - Contains only a single sequence of values with no additional structure.
- **2D vector:**
  - Has two axes (e.g. `shape = (1, 3)` or `(3, 1)`)
  - Is a matrix with either one row and multiple columns (row vector) or one column and multiple rows (column vector)
  - Is used when vectors are needed as matrices for linear algebra or as data in certain formats.
- Even though all examples have the same number of entries (e.g. 3), the structure differs due to the array's dimension.
- Understanding dimensions is important, as many NumPy operations (e.g. matrix multiplication) depend on it.
:::
