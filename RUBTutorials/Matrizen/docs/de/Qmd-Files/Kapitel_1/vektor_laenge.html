Die Länge, auch als Norm oder Betrag eines Vektors bezeichnet, ist ein Maß für seine Größe. Geometrisch entspricht sie dem Abstand vom Ursprung des Koordinatensystems bis zum Endpunkt des Vektors.

1.4.1. Mathematische Grundlagen

Die gebräuchlichste Norm ist die Euklidische Norm (oder L2-Norm). Für einen Vektor \(\vec{v} = (v_1, v_2, \dots, v_n)\) ist seine Länge \(||\vec{v}||\) definiert als die Quadratwurzel aus der Summe der quadrierten Komponenten:

\[ ||\vec{v}|| = \sqrt{v_1^2 + v_2^2 + \dots + v_n^2} \]

Wenn du genau hinsiehst, erkennst du vielleicht den Zusammenhang zum vorherigen Kapitel. Die Summe der quadrierten Komponenten ist nichts anderes als das Skalarprodukt des Vektors mit sich selbst!

\[ ||\vec{v}|| = \sqrt{\vec{v} \cdot \vec{v}} \]

Diese Verbindung ist extrem nützlich und wird in der Praxis oft verwendet, um die Länge eines Vektors zu berechnen.

Die Euklidische Norm ist ein spezifisches Beispiel für eine mathematische Norm. Eine Funktion, die Vektoren eine Länge zuordnet, wird allgemein als Norm bezeichnet, wenn sie die folgenden drei fundamentalen Eigenschaften für alle Vektoren \(\vec{v}, \vec{w}\) und jeden Skalar \(\alpha\) erfüllt:

  1. Definitheit: \(||\vec{v}|| \ge 0\) und \((||\vec{v}|| = 0 \iff \vec{v} = \vec{0})\)
  2. Absolute Homogenität: \(||\alpha \cdot \vec{v}|| = |\alpha| \cdot ||\vec{v}||\)
  3. Dreiecksungleichung: \(||\vec{v} + \vec{w}|| \le ||\vec{v}|| + ||\vec{w}||\)

1.4.2. Länge in NumPy berechnen

NumPy bietet eine dedizierte und optimierte Funktion zur Berechnung der Norm: np.linalg.norm(). Alternativ können wir die Länge auch “manuell” über das Skalarprodukt berechnen, um die Formel zu überprüfen.

Der große Vorteil ist, dass man Variablen und Ausdrücke direkt in den Text einbetten kann, indem man sie in geschweifte Klammern {} setzt. Das macht den Code oft deutlich lesbarer.

# Methode 1: Die empfohlene NumPy-Funktion

After the previous sections, all the fundamental calculations of vector arithmetic should be familiar. Often, calculations also require the **length** of a vector. We look at that in this section.

The length, also called the **norm** or **magnitude** of a vector, is a measure of its size. Geometrically, it corresponds to the distance from the origin of the coordinate system to the endpoint of the vector.

## 1.4.1. Mathematical Foundations {#mathematische-grundlagen}

The most common norm is the **Euclidean norm** (or L2 norm). For a vector $\vec{v} = (v_1, v_2, \dots, v_n)$, its length $||\vec{v}||$ is defined as the square root of the sum of the squared components:

$$ ||\vec{v}|| = \sqrt{v_1^2 + v_2^2 + \dots + v_n^2} $$

If you look closely, you might notice the connection to the [previous section](vektor_skalarprodukt.qmd). The sum of the squared components is nothing other than the dot product of the vector with itself!

$$ ||\vec{v}|| = \sqrt{\vec{v} \cdot \vec{v}} $$

This connection is extremely useful and is often used in practice to compute the length of a vector.

The Euclidean norm is a specific example of a mathematical **norm**. A function that assigns a length to vectors is generally called a norm if it satisfies the following three fundamental properties for all vectors $\vec{v}, \vec{w}$ and every scalar $\alpha$:

1.  **Positive definiteness:** $||\vec{v}|| \ge 0$ and $(||\vec{v}|| = 0 \iff \vec{v} = \vec{0})$
2.  **Absolute homogeneity:** $||\alpha \cdot \vec{v}|| = |\alpha| \cdot ||\vec{v}||$
3.  **Triangle inequality:** $||\vec{v} + \vec{w}|| \le ||\vec{v}|| + ||\vec{w}||$

## 1.4.2. Calculating Length in NumPy {#länge-in-numpy-berechnen}

NumPy provides a dedicated, optimized function for computing the norm: `np.linalg.norm()`. Alternatively, we can also calculate the length "manually" via the dot product, to verify the formula.

::: {.callout-tip title="Note: f-Strings in Python" collapse="true"}
In the following, we use so-called **f-strings** for `print()` output. An f-string is introduced by an `f` before the opening quotation mark (for example `f"Hello"`).

The big advantage is that you can embed variables and expressions directly into the text by placing them in curly braces `{}`. This often makes the code much more readable.
:::

```{pyodide-python}
import numpy as np

v_np = np.array([3, 4])

# Method 1: The recommended NumPy function
length_norm = np.linalg.norm(v_np)
print(f"Length with np.linalg.norm(): {length_norm}")

# Method 2: Manual calculation via the dot product
# This confirms the formula ||v|| = sqrt(v · v)
length_manual = np.sqrt(np.dot(v_np, v_np))
print(f"Length manually with np.sqrt(np.dot()): {length_manual}")
```

::: {.callout-tip collapse="true" title="Tips"}
*   First compute the sum of the squares of the vector components.
*   Iterate over the list (for example with a `for` loop) and add the square of each element (`element**2`) to a sum variable.
*   At the end, use `math.sqrt(your_sum)` to take the square root.

::: {.callout-caution collapse="true" title="Solution"}
With a `for` loop:

```python
def length(v):
    sum_squares = 0
    for x in v:
        sum_squares += x**2
    return math.sqrt(sum_squares)
```

::: {.callout-caution collapse="true" title="Elegant Solution"}
With `sum()` and a generator expression the code becomes much shorter:

```python
def length(v):
    return math.sqrt(sum(x**2 for x in v))
```
:::

The ability to compute the length of a vector is an important building block. It allows us, for example, to **normalize** vectors (i.e. scale them to length 1), which is a common requirement in many machine learning and computer graphics algorithms.
