Mathematisch ist das Skalarprodukt (auch inneres Produkt genannt) die Summe der Produkte der entsprechenden Komponenten zweier Vektoren. Für \(\vec{a} = (a_1, a_2, \dots, a_n)\) und \(\vec{b} = (b_1, b_2, \dots, b_n)\) ist

\[ \vec{a} \cdot \vec{b} = \sum_{i=1}^{n} a_i b_i = a_1b_1 + a_2b_2 + \dots + a_nb_n \]

Wie bei der Addition und der elementweisen Multiplikation müssen die beiden Vektoren auch für das Skalarprodukt dieselbe Dimension (also die gleiche Anzahl von Elementen) haben.

In numpy gibt es für diese Berechnung optimierte und einfach zu anzuwendende Funktionen.

Nachdem du nun die grundlegenden Vektor-Operationen kennengelernt hast, geht es in diesem Kapitel um das **Skalarprodukt**.
Diese wichtige Operation bildet aus zwei Vektoren gleicher Dimension einen einzelnen Skalar, also einen Wert. Das Skalarprodukt ist fundamental, um später Konzepte wie die Länge eines Vektors oder den Winkel zwischen zwei Vektoren zu verstehen.

## 1.3.1. Mathematische Grundlagen

Mathematisch ist das Skalarprodukt (auch inneres Produkt genannt) die Summe der Produkte der entsprechenden Komponenten zweier Vektoren. Für $\vec{a} = (a_1, a_2, \dots, a_n)$ und $\vec{b} = (b_1, b_2, \dots, b_n)$ ist

$$ \vec{a} \cdot \vec{b} = \sum_{i=1}^{n} a_i b_i = a_1b_1 + a_2b_2 + \dots + a_nb_n $$

Wie bei der Addition und der elementweisen Multiplikation müssen die beiden Vektoren auch für das Skalarprodukt dieselbe Dimension (also die gleiche Anzahl von Elementen) haben.

In `numpy` gibt es für diese Berechnung optimierte und einfach zu anzuwendende Funktionen.

```{pyodide-python}
import numpy as np

a_np = np.array([1, 2, 3])
b_np = np.array([4, 5, 6])

# Methode 1: Die Funktion np.dot()
skalarprodukt_dot = np.dot(a_np, b_np)
print(f"Skalarprodukt mit np.dot(): {skalarprodukt_dot}")

# Methode 2: Der @-Operator (Matrixmultiplikations-Operator)
# Für 1D-Arrays (Vektoren) entspricht dies dem Skalarprodukt.
skalarprodukt_at = a_np @ b_np
print(f"Skalarprodukt mit dem @-Operator: {skalarprodukt_at}")

# Zur Kontrolle: 1*4 + 2*5 + 3*6 = 4 + 10 + 18 = 32
```

Now that you've learned the basic vector operations, this chapter is about the **dot product**.
This important operation turns two vectors of equal dimension into a single scalar, i.e. a single value. The dot product is fundamental for understanding later concepts such as the length of a vector or the angle between two vectors.

## 1.3.1. Mathematical Foundations {#mathematische-grundlagen}

Mathematically, the dot product (also called the inner product) is the sum of the products of the corresponding components of two vectors. For $\vec{a} = (a_1, a_2, \dots, a_n)$ and $\vec{b} = (b_1, b_2, \dots, b_n)$ it is

$$ \vec{a} \cdot \vec{b} = \sum_{i=1}^{n} a_i b_i = a_1b_1 + a_2b_2 + \dots + a_nb_n $$

As with addition and element-wise multiplication, both vectors must have the same dimension (i.e. the same number of elements) for the dot product as well.

`numpy` provides optimized, easy-to-use functions for this calculation.

```{pyodide-python}
import numpy as np

a_np = np.array([1, 2, 3])
b_np = np.array([4, 5, 6])

# Method 1: The np.dot() function
dot_product_dot = np.dot(a_np, b_np)
print(f"Dot product with np.dot(): {dot_product_dot}")

# Method 2: The @ operator (matrix multiplication operator)
# For 1D arrays (vectors), this corresponds to the dot product.
dot_product_at = a_np @ b_np
print(f"Dot product with the @ operator: {dot_product_at}")

# Check: 1*4 + 2*5 + 3*6 = 4 + 10 + 18 = 32
```

Write a function `dot_product(a, b)` that computes the dot product of two lists of equal length without NumPy. Hidden tests check your solution automatically. Example: `dot_product([1, 2, 3], [4, 5, 6])` gives `32`.

**Commands you need:** a `for` loop with `range()` and `len()`, the index access `a[i]`, the operators `*` and `+`, `return`.

```{py-exercise}
#| label: vektor-skalarprodukt-en
#| caption: Implement dot_product
#| show-test-hints: false
def dot_product(a, b):
    # Your code here
    pass

## TESTS ##
assert dot_product([1, 2, 3], [4, 5, 6]) == 32, "Wrong result for [1,2,3] · [4,5,6]"
assert dot_product([2, 3], [4, -1]) == 5, "Wrong result for [2,3] · [4,-1]"
assert dot_product([1, 0], [0, 5]) == 0, "Orthogonal vectors have dot product 0"
```

::: {.callout-tip collapse="true" title="Tips"}
*   You need a variable to store the sum of the products. Initialize it with `0`.
*   Iterate with a `for` loop over the indices of the lists (for example with `range(len(a))`).
*   In each iteration, multiply the elements of the two lists at the current index (`a[i] * b[i]`).
*   Add this product to your sum variable.
:::

::: {.callout-caution collapse="true" title="Solution"}
With a `for` loop:

```python
def dot_product(a, b):
    result = 0
    for i in range(len(a)):
        result += a[i] * b[i]
    return result
```

::: {.callout-caution collapse="true" title="Elegant Solution"}
It is more compact with `zip()` and `sum()`. `zip()` combines the corresponding elements of the two lists into pairs: (1, 4), (2, 5), (3, 6).

```python
def dot_product(a, b):
    return sum(x * y for x, y in zip(a, b))
```
:::
