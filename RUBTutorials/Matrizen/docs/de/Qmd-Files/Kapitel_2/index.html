- [x] To make text understandable for computers (word embeddings).
- [ ] To brew coffee.
- [x] To calculate similarities between objects (e.g. cosine similarity).

> Vectors are "numeric fingerprints" of data.

# What is the difference between `.shape` and `.ndim` for a NumPy array?
1. [ ] There is none.

1. [ ] `.shape` gives the color of the array.

# What is broadcasting in NumPy?
1. [ ] A method for streaming data live to the internet.
1. [x] A mechanism that makes arrays of different sizes compatible (e.g. vector + scalar).
1. [ ] An error that occurs when matrices are too large.

> Broadcasting lets us do things like `np.array([1, 2]) + 10`, by virtually adjusting the 10.
