  • .size: Gibt die Gesamtzahl der Elemente in der Matrix an, also \(m \cdot n\).

## 2.2.2. Den Datentyp prüfen (`.dtype`) {#den-datentyp-prüfen}

Jedes Element in einem NumPy-Array hat einen bestimmten **Datentyp** (`dtype`). NumPy wählt bei der Erstellung des Arrays automatisch einen passenden Typ, zum Beispiel `int32`,`int64` für ganze Zahlen oder `float64` für Fließkommazahlen.

Der Datentyp ist wichtig für die Speichereffizienz und die numerische Präzision.

```{pyodide-python}
# NumPy erkennt automatisch den Integer-Typ
ganzzahl_matrix = np.array([
    [1, 2],
    [3, 4]
])
print(f"Datentyp der ganzzahl_matrix: {ganzzahl_matrix.dtype}")

# Sobald eine Fließkommazahl enthalten ist, wird das gesamte Array zu float
float_matrix = np.array([
    [1.0, 2],
    [3, 4]
])
print(f"Datentyp der float_matrix: {float_matrix.dtype}")
```

Now that we've learned in the [previous section](matrizen_grundlagen.qmd) what exactly a matrix is and how to create one in Python with NumPy, let's take a look in this section at how we can query its basic properties — or **attributes**. These attributes are extremely useful for understanding the structure of our data and for making sure our matrices are compatible with mathematical operations.

In NumPy, we access these attributes directly on the matrix object using dot notation (e.g. `my_matrix.shape`).

## 2.2.1. Checking Dimension, Shape and Size {#dimension-form-und-größe-prüfen}

The three most important attributes describing the structure of a matrix are its dimension (`ndim`), its shape (`shape`), and its total size (`size`).

-   `.ndim`: Gives the number of dimensions (or axes) of the array. For a matrix in the classical sense (a 2D arrangement of rows and columns), this value is always `2`.
-   `.shape`: Returns a tuple containing the number of elements along each dimension. For an $m \times n$ matrix, this is `(m, n)`.
-   `.size`: Gives the total number of elements in the matrix, i.e. $m \cdot n$.

Let's look at an example. We use the `studierenden_matrix` from the last exercise:

::: {.callout-tip title="Note: f-Strings in Python" collapse="true"}
In the following, we use so-called **f-strings** for `print()` output. An f-string is introduced by an `f` before the opening quotation mark (for example `f"Hello"`).

The big advantage is that you can embed variables and expressions directly into the text by placing them in curly braces `{}`. This often makes the code much more readable.
:::

```{pyodide-python}
import numpy as np

studierenden_matrix = np.array([
  [15, 165, 2],
  [16, 172, 1],
  [15, 168, 3]
])

# Query and print attributes
print(f"Matrix:\n{studierenden_matrix}\n")
print(f"Number of dimensions (ndim): {studierenden_matrix.ndim}")
print(f"Shape of the matrix (shape): {studierenden_matrix.shape}")
print(f"Total number of elements (size): {studierenden_matrix.size}")
```

As expected, our $3 \times 3$ matrix has 2 dimensions, the shape `(3, 3)`, and a total of $3 \cdot 3 = 9$ elements.

## 2.2.2. Checking the Data Type (`.dtype`) {#den-datentyp-prüfen}

Every element in a NumPy array has a specific **data type** (`dtype`). When creating the array, NumPy automatically chooses a suitable type, for example `int32`/`int64` for whole numbers or `float64` for floating-point numbers.

The data type matters for memory efficiency and numerical precision.

```{pyodide-python}
# NumPy automatically detects the integer type
integer_matrix = np.array([
    [1, 2],
    [3, 4]
])
print(f"Data type of integer_matrix: {integer_matrix.dtype}")

# As soon as a floating-point number is included, the entire array becomes float
float_matrix = np.array([
    [1.0, 2],
    [3, 4]
])
print(f"Data type of float_matrix: {float_matrix.dtype}")
```
