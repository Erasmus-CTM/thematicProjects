0. Willkommen zum Tutorial “Matrizen mit Python”!

Eine praktische Einführung für Studierende

Ihre Antworten werden nur in diesem Browser gespeichert.

In der linearen Algebra sind Matrizen und Vektoren zentrale Werkzeuge. Während die Berechnungen von Hand für kleine Beispiele machbar sind, werden sie bei größeren Dimensionen schnell komplex, zeitaufwendig und fehleranfällig. Hier kommt Python ins Spiel!

Dieses Tutorial zeigt dir, wie du die Konzepte der linearen Algebra (spezifisch Matrizen und Vektoren) praktisch mit Python umsetzen kannst.

0.1. Warum Python und NumPy?

0.1.1. Warum Python

Manuell sind Rechnungen mit Vektoren oder Matrizen schnell mühsam und fehleranfällig. Hilfsmittel wie Taschenrechner oder CAS (Computer-Algebra-Systeme) unterstützen hier, stoßen aber schnell an Grenzen.

Python bietet als Programmiersprache entscheidende Vorteile:
Es ermöglicht ähnlich wie bei anderen Hilfsmitteln automatisierte Berechnungen, sowie effiziente Berechnungen durch Implementierung von Bibliotheken, wie NumPy, das speziell für numerische Mathematik entwickelt wurde. Hierdurch sind große Datenmengen schnell verarbeitbar.
Dazu gibt Python die Möglichkeit Ergebnisse direkt darzustellen, mit Hilfe von zum Beispiel der Bibliothek matplotlib. Mit Python ist es ebenso möglich, Datenmengen einzulesen (dieser Teil wird in diesem Tutorial jedoch nicht gezeigt).

Damit Python solche Aufgaben übernimmt, braucht es einige Grundelemente – dazu gehören zum Beispiel:

  • Schleifen (for, while): führen Berechnungen wiederholt automatisch aus
  • Bedingte Anweisungen (if, else, elif): lassen Entscheidungen im Code (die Möglichkeit Entscheidungsbäume zu bauen), zu

0.1.2. Warum Numpy

Wir verwenden die Python-Bibliothek NumPy (Numerical Python), den De-facto-Standard für numerische Berechnungen. Im Vergleich zu nativen Python-Listen bietet NumPy entscheidende Vorteile:

  • Effizienz: NumPy-Operationen sind in C implementiert und um ein Vielfaches schneller als Berechnungen mit Python-Listen.
  • Funktionalität: NumPy stellt eine riesige Sammlung an optimierten Funktionen für die lineare Algebra bereit (zum Beispiel Determinante, Inverse, Eigenwerte).
  • Bequemlichkeit: Operationen können auf ganze Matrizen angewendet werden, ohne dass man über einzelne Elemente iterieren muss (zum Beispiel A + B).

In linear algebra, matrices and vectors are central tools. While manual calculations are feasible for small examples, they quickly become complex, time-consuming, and prone to errors with larger dimensions. This is where Python comes into play!

This tutorial shows you how to practically apply the concepts of linear algebra (specifically matrices and vectors) using Python.

## 0.1. Why Python and NumPy?

### 0.1.1. Why Python
 
Manual calculations with vectors or matrices quickly become tedious and error-prone. Tools like calculators or **CAS** (Computer Algebra Systems) provide support but soon reach their limits.

**Python** offers decisive advantages as a programming language:  
Similar to other tools, it enables automated calculations, as well as efficient computations through the implementation of libraries like `NumPy`, which was specifically developed for numerical mathematics. This allows large amounts of data to be processed quickly.  
In addition, Python provides the ability to display results directly using libraries like `matplotlib`. 
Python also makes it possible to read in datasets (however, this part is not shown in this tutorial).  

For Python to take over such tasks, it requires some basic elements – these include, for example:

- **Loops** (`for`, `while`): execute calculations repeatedly and automatically  
- **Conditional statements** (`if`, `else`, `elif`): allow decisions in the code (the ability to build decision trees)

---

### 0.1.2. Why Numpy

We use the Python library **NumPy** (Numerical Python), the de facto standard for numerical calculations. Compared to native Python lists, NumPy offers decisive advantages:

*   **Efficiency:** NumPy operations are implemented in C and are many times faster than calculations with Python lists.
*   **Functionality:** NumPy provides a huge collection of optimized functions for linear algebra (for example, determinant, inverse, eigenvalues).
*   **Convenience:** Operations can be applied to entire matrices without having to iterate over individual elements (for example, `A + B`).

### 0.2.3. Important Note: Libraries Are Shared per Page

All code blocks on a page run in the **same** Python interpreter. This means: once you import `numpy`, it stays available in every following block on the same page automatically — no need to re-import it. For almost all chapters, this will be `numpy`.

A typical first code block on a page will therefore start like this:
```{pyodide-python}
import numpy as np

# Create a vector
v = np.array([1, 2, 3])
print(v)
```

And in the next block on the same page, you can keep using `np` directly, without importing it again:
```{pyodide-python}
# 'np' from the block above is already available here
w = np.array([4, 5, 6])
print(v + w)
```

In later chapters on visualization, `matplotlib` will be added.
The same holds for variables and functions: whatever one cell has defined can be used by all later cells on the same page. The pages are therefore written to be worked through **from top to bottom**, and later cells do not repeat the code of earlier cells. If Python reports a `NameError`, you most likely have not run an earlier cell of the page yet. After reloading the page you have to run the cells again.
