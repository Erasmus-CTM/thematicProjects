# Quarto Tutorial

How to build teaching material like the other tutorials yourself, for lecturers and students.

| Level | Content |
|---|---|
| Example Page (`beg`) | A finished page that shows what is possible: layout, visuals, code, quizzes, exercises, references |
| Getting Started (`int`) | Step-by-step guides: a first website and book, exercises, interactive Python, exercises with automatic checking. Each guide comes with a printable cheat sheet |
| Tips & Tricks (`exp`) | Details for experienced users: YAML, multilingual projects, every CTM extension (Python in the browser, py-exercise, math-exercise, JSXGraph, AI feedback, quizdown) |

German, English, Swedish, Norwegian and Danish (the last three translated from English).

- Rendered site: `docs/` (serve it locally, see the [overview](../README.md)).
- Build: `python build.py --no-serve`
- Source: [github.com/Erasmus-CTM/Quarto-Tutorial](https://github.com/Erasmus-CTM/Quarto-Tutorial)
