Monotonieverhalten untersuchen

Ihre Antworten werden nur in diesem Browser gespeichert.

Monotonie

  • Eine Funktion heißt auf einem Abschnitt monoton steigend, wenn sie auf diesem Abschnitt dauerhaft eine Steigung \(\ge 0\) aufweist.
  • Eine Funktion heißt auf einem Abschnitt monoton fallend, wenn sie auf diesem Abschnitt dauerhaft eine Steigung \(\le 0\) aufweist.
  • Eine Funktion heißt auf einem Abschnitt streng monoton steigend, wenn sie auf diesem Abschnitt dauerhaft eine Steigung \(\mathbf{>} 0\) aufweist.
  • Eine Funktion heißt auf einem Abschnitt streng monoton fallend, wenn sie auf diesem Abschnitt dauerhaft eine Steigung \(\mathbf{<} 0\) aufweist.

Monotonieverhalten

Das Monotonieverhalten beschreibt, in welchen Bereichen eine Funktion welche Form der Monotonie aufweist. Die Monotonie kann, wie in dem Kapitel Ableitungen angedeutet wurde, mithilfe der Ableitung bestimmt werden, da diese an jedem Punkt die Steigung an dieser Stelle darstellt.

Um das Monotonieverhalten einer Funktion zu bestimmen, gehen wir wie folgt vor:

  1. Erste Ableitung bilden:
    Berechne die erste Ableitung \(f'(x)\) der Funktion \(f(x)\).
  2. Nullstellen der Ableitung finden:
    Bestimme die Nullstellen der ersten Ableitung, indem du die Gleichung \(f'(x) = 0\) löst. Diese Nullstellen markieren die Grenzen der Monotonie-Intervalle.
  3. Intervalle aufstellen:
    Die Nullstellen von \(f'(x)\) teilen den Definitionsbereich in die Intervalle von \(-\infty\) bis \(x_0\), von \(x_0\) bis \(x_1\), \(\dots\) und von \(x_{n-1}\) bis \(\infty\), wobei \(x_0\) bis \(x_{n-1}\) die (sortierten) Nullstellen von \(f'(x)\) sind.
  4. Vorzeichen von \(f'(x)\) prüfen:
    Wähle für jedes Intervall einen beliebigen Testwert und setze ihn in die erste Ableitung \(f'(x)\) ein. Das Vorzeichen des Ergebnisses verrät dir das Monotonieverhalten in diesem gesamten Intervall:
    • \(f'(x) > 0 \implies\) \(f\) ist streng monoton steigend.
    • \(f'(x) < 0 \implies\) \(f\) ist streng monoton fallend. Falls zwei oder mehr aufeinanderfolgende Intervalle steigend/fallend sind, kann man sie zu einem Intervall zusammenfassen. Die Funktion ist dort sogar weiterhin streng monoton, denn eine einzelne Stelle mit \(f'(x) = 0\) ändert daran nichts: \(f(x) = x^3\) ist auf ganz \(\mathbb{R}\) streng monoton steigend, obwohl \(f'(0) = 0\) gilt.

##  Aufgabe 2: als Funktion

Wenn du das hinbekommen hast, verpacke das Verfahren in eine Funktion. Ein Tupel fasst mehrere Werte zusammen, du hängst es wie jeden anderen Wert mit `append` an eine Liste. Das Gerüst steht, es fehlt der Teil in der Schleife.

```{py-exercise}
#| label: monotonie-intervalle-funktion
#| caption: monotonie_intervalle schreiben
#| show-test-hints: false
import sympy
x = sympy.symbols('x')

def monotonie_intervalle(f):
    f_strich = sympy.diff(f, x)
    stellen = sorted(sympy.solveset(f_strich, x, sympy.Reals))
    punkte = [-sympy.oo] + stellen + [sympy.oo]
    ergebnis = []
    for i in range(len(punkte) - 1):
        links, rechts = punkte[i], punkte[i + 1]
        if links == -sympy.oo and rechts == sympy.oo:
            test = 0
        elif links == -sympy.oo:
            test = rechts - 1
        elif rechts == sympy.oo:
            test = links + 1
        else:
            test = (links + rechts) / 2
        # Dein Code hier: Setze test in f_strich ein. Ist der Wert > 0, ist die Richtung 'steigend',
        # sonst 'fallend'. Hänge dann (links, rechts, richtung) an ergebnis an.
    return ergebnis

assert monotonie_intervalle(x**2) == [(-sympy.oo, 0, 'fallend'), (0, sympy.oo, 'steigend')], "x**2 fällt bis 0 und steigt danach"
```

# Monotonicity

+ A function is called **monotonically increasing** on an interval if its slope on this interval is always $\ge 0$.
+ A function is called **monotonically decreasing** on an interval if its slope on this interval is always $\le 0$.
+ A function is called ***strictly* increasing** on an interval if its slope on this interval is always $\mathbf{>} 0$.
+ A function is called ***strictly* decreasing** on an interval if its slope on this interval is always $\mathbf{<} 0$.

# Monotonic behavior

The monotonic behavior describes on which intervals a function shows which kind of monotonicity.
As hinted at in the chapter **[Derivatives](ableitungen.qmd)**, monotonicity can be determined with the help of the derivative, since it gives the slope at every point.

To determine the monotonic behavior of a function, we proceed as follows:

1.  **Compute the first derivative:**  
Compute the first derivative $f'(x)$ of the function $f(x)$.
2.  **Find the zeros of the derivative:**   
Determine the zeros of the first derivative by solving the equation $f'(x) = 0$. These zeros mark the boundaries of the monotonicity intervals.
3.  **Set up the intervals:**   
The zeros of $f'(x)$ divide the domain into the intervals from $-\infty$ to $x_0$, from $x_0$ to $x_1$, $\dots$ and from $x_{n-1}$ to $\infty$, where $x_0$ to $x_{n-1}$ are the (sorted) zeros of $f'(x)$.
4.  **Check the sign of $f'(x)$:**   
For each interval, choose any test value and plug it into the first derivative $f'(x)$. The sign of the result tells you the monotonic behavior on that whole interval:
    -   $f'(x) > 0 \implies$ $f$ is strictly increasing.
    -   $f'(x) < 0 \implies$ $f$ is strictly decreasing.
If two or more consecutive intervals are increasing/decreasing, they can be combined into one interval. The function is even still *strictly* monotonic there, because a single point with $f'(x) = 0$ does not change that: $f(x) = x^3$ is strictly increasing on all of $\mathbb{R}$, although $f'(0) = 0$.

## The connection in a picture

In the following plot you see $f(x) = x^3 - 3x^2 + 2$ together with its derivative $f'(x)$. Pay attention: wherever $f'$ lies **above** the $x$-axis, $f$ increases; where $f'$ lies **below** it, $f$ decreases. This changes at the zeros of $f'$. With the magnifier from the toolbar you can look at these points more closely.

```{pyodide-python}
#| read-only: true
import numpy as np
import matplotlib.pyplot as plt

x_values = np.linspace(-1.5, 3.5, 400)
f_values = x_values**3 - 3*x_values**2 + 2
f_prime = 3*x_values**2 - 6*x_values

plt.plot(x_values, f_values, label="f(x)")
plt.plot(x_values, f_prime, "--", label="f'(x)")
plt.axhline(0, color="black", linewidth=0.8)
plt.fill_between(x_values, f_prime, 0, where=f_prime > 0, alpha=0.15, color="green", label="f' > 0: f increases")
plt.fill_between(x_values, f_prime, 0, where=f_prime < 0, alpha=0.15, color="red", label="f' < 0: f decreases")
plt.ylim(-5, 8)
plt.legend()
plt.grid(True)
plt.show()
```

#### For loop 

`For loops` repeat over a certain range. The keyword `range` describes the range from $a$ to $b$. Here $a$ is the start of the iteration; $b$ itself is **not** included: `range(5, 20)` runs from 5 to 19.

```{pyodide-python}
a = 5 
b = 20
for i in range(a,b,2): #a and b are the bounds, 2 is the step size
    print(i+1)
```
