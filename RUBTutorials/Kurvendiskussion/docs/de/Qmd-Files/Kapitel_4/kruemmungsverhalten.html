Was ist die Krümmung?

Die Krümmung einer Funktion beschreibt, wie sich der Graph “krümmt”, bzw. “biegt”, das heißt wie weit sich die Funktion von einer Geraden entfernt. Es hilft, sich das als Analogie mit Hilfe einer Straße vorzustellen, die Krümmung gibt an, ob die Straße nach rechts oder nach links abknickt und wie stark der Knick ist.
Die Krümmung einer Funktion erkennt man am Monotonieverhalten der ersten Ableitung: Steigt \(f'\), ist \(f\) linksgekrümmt, fällt \(f'\), ist \(f\) rechtsgekrümmt. Dort, wo sich das Monotonieverhalten von \(f'\) ändert, liegen die Wendestellen.
Wichtig: Bei Betrachtung des “Monotonieverhaltens” darf nicht außer Acht gelassen werden, dass hier das Monotonieverhalten der ersten Ableitung betrachtet wird. Mathematisch unterscheiden wir zwei Hauptarten der Krümmung:

  • Linksgekrümmt (konvex): Der Graph “knickt” sich nach oben. Wenn man sich auf dem Graphen bewegt, biegt er sich nach links.
  • Rechtsgekrümmt (konkav): Der Graph “knickt” sich nach unten. Wenn man sich auf dem Graphen bewegt, biegt er sich nach rechts.

Krümmungsverhalten bestimmen

Um das Krümmungsverhalten einer Funktion zu bestimmen, nutzen wir die zweite Ableitung \(f''(x)\). Sie ist die Ableitung von \(f'\) und zeigt deshalb, ob \(f'\) steigt oder fällt. Die Schritte zur Bestimmung des Krümmungsverhaltens sind wie folgt:

  1. Zweite Ableitung bilden: Berechne die zweite Ableitung \(f''(x)\) der Funktion \(f(x)\).
  2. Nullstellen der zweiten Ableitung finden: Bestimme die Nullstellen der zweiten Ableitung, indem du die Gleichung \(f''(x) = 0\) löst. Diese Nullstellen sind potenzielle Wendepunkte, an denen sich das Krümmungsverhalten ändern könnte.
  3. Intervalle aufstellen: Die Nullstellen von \(f''(x)\) bilden die Grenzen der Intervalle.
  4. Vorzeichen von \(f''(x)\) prüfen: Wähle für jedes Intervall einen beliebigen Wert innerhalb des Intervalls aus. Setze diesen Wert in \(f''(x)\) ein. Das Vorzeichen des Ergebnisses verrät dir das Krümmungsverhalten in diesem gesamten Intervall:
    • \(f''(x) > 0 \implies\) Der Graph ist in diesem Intervall linksgekrümmt (konvex).
    • \(f''(x) < 0 \implies\) Der Graph ist in diesem Intervall rechtsgekrümmt (konkav).

# Python Implementierung

Wenn die oben kurzgefasste Theorie verstanden ist kann betrachtet werden, wie das Ganze in Python implementiert werden kann.  

```{pyodide-python}
#| read-only: true
import sympy
x = sympy.symbols('x')
f = x**4 - 4*x**3 + 2

print(f"Die Funktion ist: f(x) = {f}")
f_prime = sympy.diff(f, x)
print(f"f'(x) = {f_prime}")
f_double_prime = sympy.diff(f_prime, x)
print(f"f''(x) = {f_double_prime}")

potentielle_wendepunkte = sympy.solve(f_double_prime, x)
potentielle_wendepunkte.sort() 
print(f"Die Nullstellen der zweiten Ableitung sind: {potentielle_wendepunkte}")

intervall_grenzen = [-sympy.oo] + potentielle_wendepunkte + [sympy.oo]

print("\n--- Untersuchung des Krümmungsverhaltens ---")
for i in range(len(intervall_grenzen) - 1):
    untere_grenze = intervall_grenzen[i]
    obere_grenze = intervall_grenzen[i+1]

    # Hier wird der Mittelpunkt des Intervalls betrachtet (falls die Grenzen endlich sind)
    if untere_grenze == -sympy.oo:
        test_wert = obere_grenze - 1 if obere_grenze != sympy.oo else 0
    elif obere_grenze == sympy.oo:
        test_wert = untere_grenze + 1
    else:
        test_wert = (untere_grenze + obere_grenze) / 2

    f_double_prime_at_test_wert = f_double_prime.subs(x, test_wert)
```

# What is concavity?

The **concavity** (curvature) of a function describes how the graph "curves" or "bends", i.e. how far the function deviates from a straight line. It helps to imagine a road: the curvature tells you whether the road bends to the right or to the left and how sharp the bend is.  
The concavity of a function can be seen from the **[monotonicity](monotonieverhalten.qmd)** of the first derivative: if $f'$ increases, $f$ is concave up; if $f'$ decreases, $f$ is concave down. Where the monotonicity of $f'$ changes, there are inflection points.  
**Important**: When looking at this "monotonicity", keep in mind that we are looking at the monotonicity of the first **derivative**.
Mathematically, we distinguish **two main kinds of concavity**:

*   **Concave up (convex)**: The graph "bends" upwards. If you move along the graph, it bends to the left.
*   **Concave down (concave)**: The graph "bends" downwards. If you move along the graph, it bends to the right.

## Determining concavity

To determine the concavity of a function, we use the **second derivative** $f''(x)$, It is the derivative of $f'$ and therefore shows whether $f'$ increases or decreases.
The **steps for determining concavity** are as follows:

1.  **Compute the second derivative:** Compute the second derivative $f''(x)$ of the function $f(x)$.
2.  **Find the zeros of the second derivative:** Determine the zeros of the second derivative by solving the equation $f''(x) = 0$. These zeros are **potential inflection points**, where the concavity might change.
3.  **Set up the intervals:** The zeros of $f''(x)$ form the boundaries of the intervals.
4.  **Check the sign of $f''(x)$:** For each interval, choose any value inside it and plug it into $f''(x)$. The sign of the result tells you the concavity on that whole interval:
    *   $f''(x) > 0 \implies$ The graph is **concave up (convex)** on this interval.
    *   $f''(x) < 0 \implies$ The graph is **concave down (concave)** on this interval.

## Concavity in a picture

The following plot shows $f(x) = x^4 - 4x^3 + 2$. The green background marks the regions where $f''(x) > 0$ (concave up), the red one those with $f''(x) < 0$ (concave down). Imagine riding a bike from left to right along the graph: in the green region you steer to the left, in the red one to the right.

```{pyodide-python}
#| read-only: true

plt.fill_between(x_values, bottom, top, where=f_2prime < 0, color="red", alpha=0.12, label="f'' < 0: concave down")
plt.ylim(bottom, top)
plt.legend()
plt.grid(True)
plt.show()
```

# Python implementation

Once the theory summarized above is understood, we can look at how the whole thing can be implemented in Python.  

```{pyodide-python}
#| read-only: true
import sympy
x = sympy.symbols('x')
f = x**4 - 4*x**3 + 2

print(f"The function is: f(x) = {f}")
f_prime = sympy.diff(f, x)
print(f"f'(x) = {f_prime}")
f_double_prime = sympy.diff(f_prime, x)
print(f"f''(x) = {f_double_prime}")

potential_inflection_points = sympy.solve(f_double_prime, x)
potential_inflection_points.sort() 
print(f"The zeros of the second derivative are: {potential_inflection_points}")

interval_bounds = [-sympy.oo] + potential_inflection_points + [sympy.oo]

print("\n--- Examining the concavity ---")
for i in range(len(interval_bounds) - 1):
    lower_bound = interval_bounds[i]
    upper_bound = interval_bounds[i+1]

    # Here we look at the midpoint of the interval (if the bounds are finite)
    if lower_bound == -sympy.oo:
        test_value = upper_bound - 1 if upper_bound != sympy.oo else 0
    elif upper_bound == sympy.oo:
        test_value = lower_bound + 1
    else:
        test_value = (lower_bound + upper_bound) / 2

    f_double_prime_at_test_value = f_double_prime.subs(x, test_value)
```
