# Wendepunkt

Als **Wendepunkt** wird ein Punkt einer Funktion bezeichnet, an dem sich das Krümmungsverhalten der Funktion ändert.
Das heißt, ähnlich wie bei den **Extremwerten** und dem **Monotonieverhalten** verhält es sich auch bei den **Wendepunkten** und dem **Krümmungsverhalten**.

Falls du also noch nicht den Abschnitt **[Krümmungsverhalten](kruemmungsverhalten.qmd)** bearbeitet hast, kannst du das über den Link nachholen. Wissen aus dem Abschnitt wird hier vorausgesetzt.

Als kleine Erinnerung an den anderen Abschnitt:
```{pyodide-python}
#| read-only: true
import sympy
x = sympy.symbols('x')
f = x**4 - 4*x**3 + 2

print(f"Die Funktion ist: f(x) = {f}")
f_prime = sympy.diff(f, x)
print(f"f'(x) = {f_prime}")
f_double_prime = sympy.diff(f_prime, x)
print(f"f''(x) = {f_double_prime}")

potentielle_wendepunkte = sympy.solve(f_double_prime, x)
potentielle_wendepunkte.sort() 
print(f"Die Nullstellen der zweiten Ableitung sind: {potentielle_wendepunkte}")
```

**Kurz überlegt:** Wendepunkte findest du über die zweite Ableitung. Einmal von Hand:

```{math-exercise}
#| label: wendepunkte-vorcheck
#| caption: Vorab-Check – Wendestelle von Hand
#| vars: x
#| field-labels: g''(x), Wendestelle
#| partial-credit: true
Für $g(x)=x^3-3x^2$ gilt $g''(x)=$ __[6*x-6]. Die Krümmung wechselt bei $x=$ _[1].
```

# Inflection point

An **inflection point** is a point of a function at which the concavity of the function changes.
In other words, **inflection points** relate to **concavity** in much the same way as **extrema** relate to **monotonicity**.

So if you have not yet worked through the section **[Concavity](kruemmungsverhalten.qmd)**, you can catch up via the link. Knowledge from that section is assumed here.

As a small reminder of the other section:
```{pyodide-python}
#| read-only: true
import sympy
x = sympy.symbols('x')
f = x**4 - 4*x**3 + 2

print(f"The function is: f(x) = {f}")
f_prime = sympy.diff(f, x)
print(f"f'(x) = {f_prime}")
f_double_prime = sympy.diff(f_prime, x)
print(f"f''(x) = {f_double_prime}")

potential_inflection_points = sympy.solve(f_double_prime, x)
potential_inflection_points.sort() 
print(f"The zeros of the second derivative are: {potential_inflection_points}")
```

**Quick check:** You find inflection points via the second derivative. Once by hand:

```{math-exercise}
#| label: wendepunkte-vorcheck-en
#| caption: Pre-check – inflection point by hand
#| vars: x
#| field-labels: g''(x), inflection point
#| partial-credit: true
For $g(x)=x^3-3x^2$ we have $g''(x)=$ __[6*x-6]. The concavity changes at $x=$ _[1].
```
