Was ist ein Extrempunkt/Sattelpunkt?

Als Extrempunkt oder auch Extremum wird ein Punkt bezeichnet, der “tiefer,höher” als alle anderen Punkte im Umfeld liegt. Als Analogie können ein Berg, bzw. ein Tal betrachtet werden.

  • Die Spitze des Bergs ist ein Hochpunkt, also ein Extrempunkt, der höher ist als nebenliegende Funktionswerte.
  • Die tiefste Stelle ist ein Tiefpunkt, also ein Extrempunkt, der niedriger ist als nebenliegende Funktionswerte.
    Im weiteren Verlauf dieses Kapitels wird die Benennung Minimum = Tiefpunkt und Maximum = Hochpunkt genutzt.

Lokale vs. Globale Extrema

Die Differenzierung zwischen lokalen und globalen Extrempunkten ist nicht so leicht zu verstehen.
Eine Funktion kann mehrere lokale Extrema haben, jedoch höchstens einen globalen Maximalwert und höchstens einen globalen Minimalwert (dieser kann aber an mehreren Stellen angenommen werden, z.B. bei \(\sin(x)\)).
Eine Funktion hat an der Stelle \(x\) sicher ein Extremum, wenn die folgenden zwei Bedingungen erfüllt sind. Die erste ist notwendig (ohne sie gibt es kein Extremum), beide zusammen sind hinreichend.

  1. \(f'(x)=0\) Das bedeutet, dass an der Stelle die Steigung Null ist, der Wert nicht weiter ansteigt/abfällt.
  2. \(f''(x) \neq 0\) Das bedeutet, dass an der Stelle die Krümmung entweder positiv, oder negativ ist. Dies sorgt dafür, dass sich das Monotonieverhalten ändert. Ist \(f''(x) = 0\), kann trotzdem ein Extremum vorliegen (siehe Hinweis-Kasten unten).

Der 2. Punkt kann auch anders geprüft werden. Falls die zweite Ableitung nicht bestimmt werden soll, kann ein Wert minimal kleiner und minimal größer als \(x\) in die Ableitung eingesetzt werden, wenn sich die Vorzeichen unterscheiden, so ist dort ein Extremum.
Falls für den kleineren \(x\)-Wert das Vorzeichen Minus, und für den größeren Plus ist, handelt es sich um einen Tiefpunkt,
Falls für den kleineren \(x\)-Wert das Vorzeichen Plus und für den größeren Minus ist, handelt es sich um einen Hochpunkt.

Globale Extrema

Damit ein lokales Maximum/Minimum ein globales Maximum/Minimum ist, muss eine weitere Bedingung gelten:
Für ein globales Maximum \(x_{max}\) gilt, \(f(x_{max}) \ge f(x) \forall x \in Def.Bereich\)
Für ein globales Minimum \(x_{min}\) gilt, \(f(x_{min}) \le f(x) \forall x \in Def.Bereich\)

Sattelpunkte

Als Sattelpunkt wird ein potentielles Extremum bezeichnet, welches jedoch keines ist.
Potentiell insoweit, als dass für einen Sattelpunkt gilt, dass: \(f'(x_{sat})=0\) aber im Gegensatz zum Extremum muss für die zweite Ableitung gelten, dass \(f''(x_{sat})=0\).
Ein Sattelpunkt ist also ein Punkt in einer Funktion an dem die Steigung Null ist, sich vorher und nachher in der Ausrichtung der Funktion jedoch nichts ändert.

WarnungVorsicht bei \(f''(x) = 0\)

\(f''(x) = 0\) allein reicht noch nicht für einen Sattelpunkt. Beispiel: \(f(x) = x^4\) hat bei \(x=0\) sowohl \(f'(0)=0\) als auch \(f''(0)=0\), trotzdem ist dort ein Tiefpunkt. Andersherum heißt das auch: Die Bedingung \(f''(x)\neq 0\) oben ist hinreichend für ein Extremum, aber nicht notwendig.

Sicher bist du auf zwei Wegen:

  • mit der dritten Ableitung: Gilt \(f'(x)=0\), \(f''(x)=0\) und \(f'''(x)\neq 0\), dann ist es ein Sattelpunkt.
  • mit dem Vorzeichenwechsel von \(f'\) (siehe Aufgabe 2 unten): Wechselt \(f'\) das Vorzeichen, ist es ein Extremum, sonst ein Sattelpunkt.

# Python Implementierung

Nachdem dir nun klar sein sollte, was noch mal ein Extrempunkt/Sattelpunkt ist, wird die Implementierung in Python betrachtet.

```{pyodide-python}
#| read-only: true
import sympy
x = sympy.symbols('x')
f = x**3 - 3*x**2 + 2
print(f"f(x) = {f}")

f_prime = sympy.diff(f, x) #Erste Ableitung
print(f"f'(x) = {f_prime}")

critical_points = sympy.solve(f_prime, x) #Nullstellen der ersten Ableitung
print(f"Die Nullstellen der ersten Ableitung sind: {critical_points}")

f_double_prime = sympy.diff(f_prime, x) # Zweite Ableitung
print(f"f''(x) = {f_double_prime}")

print("\n--- Test für potentielle Extrema ---")
for cp in critical_points: #Die Liste der Punkte in critical_points wird durchlaufen, mit cp als Laufindex
    f_double_prime_at_cp = f_double_prime.subs(x, cp)
    y_value = f.subs(x, cp) #setzt cp in ursprüngliche Funktion f ein

    if f_double_prime_at_cp > 0:
        print(f"Bei x = {cp} ,y = {y_value} liegt ein Tiefpunkt vor (f''({cp}) = {f_double_prime_at_cp} > 0).")
    elif f_double_prime_at_cp < 0: #elif bedeutet Else If, also "falls nicht, wenn, dann...""
        print(f"Bei x = {cp} ,y = {y_value} liegt ein Hochpunkt vor (f''({cp}) = {f_double_prime_at_cp} < 0).")
```

```{py-exercise}
#| label: extrempunkte-vzw-funktion
#| caption: extremstellen_vzw schreiben
#| show-test-hints: false
import sympy
x = sympy.symbols('x')

def extremstellen_vzw(funktion_f):
    f_strich = sympy.diff(funktion_f, x)
    ergebnis = []
    for k in sympy.solve(f_strich, x):
        if not k.is_real:
            continue                       # komplexe Lösungen überspringen
        links = f_strich.subs(x, k - sympy.Rational(1, 100))    # f' knapp links von k
        rechts = f_strich.subs(x, k + sympy.Rational(1, 100))   # f' knapp rechts von k
        # Dein Code hier: Hänge k an ergebnis an, falls links und rechts ein anderes Vorzeichen haben
    return sorted(ergebnis)
```

# What is an extremum/saddle point?

An **extreme point** or **extremum** is a point that lies "lower/higher" than all other points in its neighborhood. Think of a mountain or a valley.  

* The top of the mountain is a *maximum*, i.e. an extreme point that is higher than the neighboring function values.  
* The lowest point of the valley is a *minimum*, i.e. an extreme point that is lower than the neighboring function values.  
_In the rest of this chapter, we use the terms minimum = low point and maximum = high point._

## Local vs. global extrema
The distinction between *local and global extrema* is not that easy to understand.  
A function can have several *local extrema*, but *at most one global maximum value and at most one global minimum value* (which can, however, be attained at several points, e.g. for $\sin(x)$).   
A function **definitely has an extremum** at the point $x$ if the following **two conditions** are met. The first one is necessary (without it there is no extremum); together they are sufficient.

1.  $f'(x)=0$ This means that the slope at this point is zero; the value does not keep rising/falling.  
2.  $f''(x) \neq 0$ This means that the **[concavity](kruemmungsverhalten.qmd)** at this point is either positive or negative. This makes the monotonic behavior change. If $f''(x) = 0$, there can still be an extremum (see the box below).  

_The 2nd point can also be checked differently. If you do not want to compute the second derivative, you can plug a value slightly smaller and slightly larger than $x$ into the derivative; if the signs differ, there is an extremum.  
If the sign is minus for the smaller $x$-value and plus for the larger one, it is a **minimum**;   
if the sign is plus for the smaller $x$-value and minus for the larger one, it is a **maximum**._  


### Global extrema 
For a *local maximum/minimum* to be a *global maximum/minimum*, a further condition must hold:  
For a *global maximum* $x_{max}$: $f(x_{max}) \ge f(x) \forall x \in \text{domain}$  
For a *global minimum* $x_{min}$: $f(x_{min}) \le f(x) \forall x \in \text{domain}$  

## Saddle points

A **saddle point** is a potential extremum that turns out not to be one.  
Potential in the sense that for a saddle point **it holds that:** $f'(x_{sat})=0$, **but** unlike an extremum, the second derivative must satisfy $f''(x_{sat})=0$.  
So a *saddle point* is a point of a function where the slope is zero, but the direction of the function does not change before and after it.

::: {.callout-warning title="Careful with $f''(x) = 0$"}
$f''(x) = 0$ alone is not enough for a saddle point. Example: $f(x) = x^4$ has both $f'(0)=0$ and $f''(0)=0$ at $x=0$, yet there is a **minimum** there. Conversely, this also means: the condition $f''(x)\neq 0$ above is *sufficient* for an extremum, but not *necessary*.

You are on the safe side in two ways:

- with the **third derivative**: if $f'(x)=0$, $f''(x)=0$ **and** $f'''(x)\neq 0$, it is a saddle point.
- with the **sign change** of $f'$ (see exercise 2 below): if $f'$ changes sign, it is an extremum, otherwise a saddle point.
:::

**Quick check:** Before you program, calculate once by hand. Is the procedure solid (differentiate, set to zero, plug into the second derivative)?

```{math-exercise}

#| caption: Pre-check – extremum by hand
#| vars: x

#| partial-credit: true
For $g(x)=x^2-4x$ we have $g'(x)=$ __[2*x-4]. The derivative is zero at $x=$ _[2] and the second derivative there is $g''(x)=$ _[2]. Since $g''>0$, there is a minimum.
```

# Python implementation

Now that it should be clear to you again what an extremum/saddle point is, let's look at the implementation in Python.

```{pyodide-python}
#| read-only: true
import sympy
x = sympy.symbols('x')
f = x**3 - 3*x**2 + 2
print(f"f(x) = {f}")

f_prime = sympy.diff(f, x) #first derivative
print(f"f'(x) = {f_prime}")

critical_points = sympy.solve(f_prime, x) #zeros of the first derivative
print(f"The zeros of the first derivative are: {critical_points}")

f_double_prime = sympy.diff(f_prime, x) #second derivative
print(f"f''(x) = {f_double_prime}")

print("\n--- Test for potential extrema ---")
for cp in critical_points: #the list of points in critical_points is traversed, with cp as the loop variable
    f_double_prime_at_cp = f_double_prime.subs(x, cp)
    y_value = f.subs(x, cp) #plugs cp into the original function f

    if f_double_prime_at_cp > 0:
        print(f"At x = {cp}, y = {y_value} there is a minimum (f''({cp}) = {f_double_prime_at_cp} > 0).")
    elif f_double_prime_at_cp < 0: #elif means else if, i.e. "if not, then if..."
        print(f"At x = {cp}, y = {y_value} there is a maximum (f''({cp}) = {f_double_prime_at_cp} < 0).")
```
