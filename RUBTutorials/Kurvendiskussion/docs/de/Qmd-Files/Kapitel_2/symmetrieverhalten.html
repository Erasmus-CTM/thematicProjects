Eine Funktion $f(x)$ ist punktsymmetrisch zum Ursprung, wenn für alle $x$ im Definitionsbereich gilt: $f(-x) = -f(x)$ (oder analog $-f(-x) = f(x)$). 

**Kurz überlegt:** Der ganze Test beruht darauf, $-x$ statt $x$ einzusetzen. Sitzt das?

```{math-exercise}
#| label: symmetrie-vorcheck
#| caption: Vorab-Check – f(-x) bilden
#| vars: x
Für $f(x)=x^4-3x^2$ ist $f(-x)=$ __[x**4-3*x**2]. Für $g(x)=x^3+x$ ist $g(-x)=$ __[-x**3-x]. Vergleiche jeweils mit $f(x)$ bzw. $-g(x)$.
```

## Wie teste ich eine Funktion auf Achsensymmetrie zur Y-Achse?

Die Grundidee ist ähnlich wie in anderen Kapiteln. 
Wir nutzen `sympy`. Mit dieser Bibliothek können wir Funktionen als mathematische Objekte betrachten, deren Eigenschaften wir untersuchen können.
Zuvor müssen wir unsere Variable als **Symbol** definieren, damit das Programm diese Variable anders als andere Python-Variablen nutzt.

```{pyodide-python}
#| label: symmetrie-beispiel-achse
import sympy
x = sympy.symbols('x')

# Funktion hier eingeben:
f1 = x**2 + 4

def pruefe_achsensymmetrie(funktion_f):
    # Ersetze jedes Vorkommen von x in der Funktion durch -x
    f_minus_x = funktion_f.subs(x, -x)
    if sympy.simplify(funktion_f - f_minus_x) == 0:
        return True
    else:
        return False

ist_symmetrisch = pruefe_achsensymmetrie(f1)

print(f"Die Funktion f(x) = {f1} wird auf Achsensymmetrie zur Y-Achse untersucht ...")

if ist_symmetrisch:
    print("Ergebnis: Die Funktion ist achsensymmetrisch zur Y-Achse.")
else:
    print("Ergebnis: Die Funktion ist NICHT achsensymmetrisch zur Y-Achse.")


```

# What kinds of symmetry are there?

In general, we distinguish between **point symmetry and axis symmetry**.
In this tutorial, as at school, we mainly deal with symmetry about the y-axis and point symmetry about the origin.
It is important to note that not every function shows some form of symmetry.
There are functions that are axis-symmetric but whose axis of symmetry is not the y-axis (e.g. shifted parabolas like $f(x) = (x-1)^2$).
There are also functions that are point-symmetric, but not about the origin.

A small reminder of the forms of symmetry considered in this tutorial:

1.  **Symmetry about the y-axis:**  
A function $f(x)$ is symmetric about the y-axis if for all $x$ in the domain: $f(x) = f(-x)$.

2.  **Point symmetry about the origin:**   
A function $f(x)$ is point-symmetric about the origin if for all $x$ in the domain: $f(-x) = -f(x)$ (or equivalently $-f(-x) = f(x)$). 

**Quick check:** The whole test rests on plugging in $-x$ instead of $x$. Is that clear?

```{math-exercise}
#| label: symmetrie-vorcheck-en
#| caption: Pre-check – forming f(-x)
#| vars: x
For $f(x)=x^4-3x^2$ we have $f(-x)=$ __[x**4-3*x**2]. For $g(x)=x^3+x$ we have $g(-x)=$ __[-x**3-x]. Compare with $f(x)$ and $-g(x)$ respectively.
```

## How do I test a function for symmetry about the y-axis?

The basic idea is similar to other chapters. 
We use `sympy`. With this library, we can treat functions as mathematical objects whose properties we can examine.
Before that, we have to define our variable as a **symbol**, so that the program treats this variable differently from other Python variables.

```{pyodide-python}
#| label: symmetrie-beispiel-achse-en
import sympy
x = sympy.symbols('x')

# Enter the function here:
f1 = x**2 + 4

def check_axis_symmetry(function_f):
    # Replace every occurrence of x in the function with -x
    f_minus_x = function_f.subs(x, -x)
    if sympy.simplify(function_f - f_minus_x) == 0:
        return True
    else:
        return False

is_symmetric = check_axis_symmetry(f1)

print(f"The function f(x) = {f1} is checked for symmetry about the y-axis ...")

if is_symmetric:
    print("Result: The function is symmetric about the y-axis.")
else:
    print("Result: The function is NOT symmetric about the y-axis.")


```
