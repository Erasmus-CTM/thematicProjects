Definitionsbereich und Wertebereich

Der Definitionsbereich

Der Definitionsbereich (auch Definitionsmenge genannt) einer Funktion \(f\) ist die Menge aller Werte, für die die Funktion definiert ist, das heißt für die ein gültiger Funktionswert berechnet werden kann. Mit Python und der Bibliothek SymPy können wir versuchen, den Definitionsbereich für verschiedene Arten von Funktionen zu bestimmen. SymPy erlaubt uns, mit mathematischen Symbolen und Ausdrücken zu arbeiten. Also um Gleichungen zu lösen.

Es gibt zwei Gründe, warum eine Funktion eine Definitionslücke hat, beide hängen von den jeweiligen Begrenzungen unserer Begriffe ab.
Zum einen gebrochen-rationale Funktionen bzw. Brüche. Die Division durch Null ist nicht definiert, daher hat jede Funktion eine Definitionslücke, wenn sonst durch 0 geteilt werden würde an der Stelle.
Zum anderen Funktionen mit Wurzeln gerade Wurzeln (2.,4.,\(\dots\) Wurzel) sind für negative Zahlen nicht definiert (Es sei denn man befindet sich in ℂ). Da negative Werte innerhalb einer Wurzel nicht definiert sind, gibt es auch hier eine Definitionslücke, für alle Werte an denen die Funktion einen negativen Wert der Wurzel wiedergeben würde.

Wir betrachten die unterschiedlichen Untersuchungen getrennt, natürlich können die beiden Untersuchungen auch in einem Python-Programm abgearbeitet werden.

Der Wertebereich

Der Wertebereich (auch Wertemenge genannt) einer Funktion \(f\) ist die Menge aller Werte, die diese Funktion annehmen kann, das heißt die Menge aller Werte welche durch Einsetzen aller Elemente aus dem Definitionsbereich bestimmt werden. Der Wertebereich einer Funktion kann aus verschiedenen Gründen eingeschränkt sein, es gibt den trivialen Fall, der auch untersucht werden kann, den wir hier aber der Übersichtlichkeit wegen wegfallen lassen. Obendrein wird empfohlen erst die anderen Kapitel durchzuarbeiten, da für das Kapitel Wertebereich unter anderem Extremwerte wichtig sind, aber auch Asymptoten und Verhalten der Funktion an Grenzen oder im Unendlichen beinhaltet.

Es gibt zum einen strukturelle Eigenschaften der Funktion welche den Wertebereich einschränken können. Darunter fällt das Vorhandensein von globalen Extremwerten und natürliche Wertegrenzen bestimmter Funktionstypen (Exponentialfunktionen, Wurzelfunktionen, Betragsfunktionen, Trigonometrische Funktion, Periodische Funktionen) Auch spielt das Verhalten der Funktion an Grenzen oder im Unendlichen eine Rolle, dies bezieht sich vor allem auf horizontale Asymptoten, denen sich die Funktion annähert und die deshalb oft eine Grenze des Wertebereichs bilden.

# The domain

The **[domain](definitionsbereich.qmd)** of a function **$f$** is the set of all values for which the function is defined, i.e. for which a valid function value can be calculated.
With Python and the library `SymPy`, we can try to determine the domain for different kinds of functions. `SymPy` lets us work with mathematical symbols and expressions, for example to solve equations.

There are two reasons why a function can have a gap in its domain; both come from the limits of the operations involved.  
First, **[rational functions](definitionsbereich.qmd#rational-functions)**, i.e. fractions. Division by zero is not defined, so a function has a gap wherever it would otherwise divide by 0.  
Second, **[functions with roots](definitionsbereich.qmd#functions-with-roots)**: even roots (square root, 4th root, $\dots$) are not defined for negative numbers (unless you work in ℂ). Since negative values inside such a root are not defined, there is a gap here as well, for all values at which the expression under the root would be negative.

We look at the two kinds of analysis separately; of course, both can also be carried out in one Python program.

# The range

The **[range](wertebereich.qmd)** (also called the image) of a function **$f$** is the set of all values the function can take, i.e. the set of all values obtained by plugging in every element of the domain.
The range of a function can be restricted for various reasons. There is also the trivial case, which could be examined too, but we leave it out here to keep things clear. 
In addition, we recommend working through the other chapters first, since the chapter on the range relies on **[extrema](../Kapitel_4/extrempunkte.qmd)**, but also on **[asymptotes](../Kapitel_3/asymptoten.qmd)** and the **[behavior of the function at boundaries or at infinity](../Kapitel_3/globalverhalten.qmd)**.  

On the one hand, there are **structural properties of the function** that can restrict the range. 
These include the existence of **global extrema** and **natural bounds of certain types of functions** (exponential functions, root functions, absolute value functions, trigonometric functions, periodic functions).
The **behavior of the function at boundaries or at infinity** also plays a role, mainly because of **horizontal asymptotes**, which the function approaches and which therefore often form a bound of the range.
