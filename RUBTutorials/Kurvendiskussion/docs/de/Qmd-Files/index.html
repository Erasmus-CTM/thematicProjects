**Goal of the tutorial:**  
The tutorial is meant to introduce you to Python using curve sketching, a classic topic of the German Abitur (school-leaving exam).  
Step by step, we go through the steps of curve sketching and show how each of them can be carried out with Python.  

In this tutorial you will often see **code blocks** like the following. These are **Pyodide Python blocks**; you can run them with the **arrow symbol (▶)**, which executes the code inside them.  
```{pyodide-python}
#| read-only: true
#Some code blocks cannot be edited
print("Hello World!")
```

```{pyodide-python}
#Other code blocks can be edited
print("Hello World?")
#As a test, feel free to change "Hello World?" to an output of your choice.
```

A Python environment is built into the code blocks.  
This means you can program in them just like in Python!  

:::{.callout-tip title="More about the code blocks"}
**Running and stopping:** Besides the arrow, you can also run a block with **Shift + Enter**. Python runs in the background, so the page stays usable. If something takes too long (for example an endless loop), you can abort it with **Stop**.

**On the right of the bar** you find <i class="fa-solid fa-arrows-rotate"></i> (reset the block to its original code), <i class="fa-regular fa-copy"></i> (copy the code) and **+ Code block**, which appends another empty block below for trying things out.

**Your code is saved:** Whatever you write in editable blocks is saved in this browser and restored on your next visit (but not run automatically). Next to "Editable" it then says "💾 Saved". With <i class="fa-solid fa-trash-can"></i> you delete the saved version of a block. In the <i class="fa-solid fa-gear"></i> menu at the top right of every page you can turn saving off or delete everything that was saved, e.g. on a shared computer.
:::

:::{.callout-note title="Setting up AI feedback" collapse="true"}
Below editable blocks there is a **Feedback** button. An AI then looks at your code and its output and gives you a hint. With every further click on the same block, the hint becomes more concrete (first a nudge, then the problem named concretely, then the solution approach in words). You never get finished code, though, so you still have to do the programming yourself.

You set this up **once** via the <i class="fa-solid fa-gear"></i> symbol at the top right of the page; after that it applies to all pages and to your next visit as well:

- **Without an account:** Choose the feedback mode **"Copy prompt (no API key)"** and save. Clicking Feedback then creates a ready-made text that you paste into ChatGPT, Claude or similar.
- **With a free account**, using OpenRouter as an **example** (this is not a recommendation by the authors, other providers work just as well): Create a free account at [OpenRouter](https://openrouter.ai) and generate a key (API key) at [openrouter.ai/keys](https://openrouter.ai/keys). In the <i class="fa-solid fa-gear"></i> menu, choose the **provider template "OpenRouter"**, paste the key and save. With **Fetch models** you can pick a different model; by default only free ones are shown. The button **ℹ️ How do I get credentials?** explains this for other providers as well.

Your key stays in your browser. When you click Feedback, however, your code and the exercise are sent to the chosen provider.

The **calculation exercises** have their own Feedback button. On the first click, a separate settings window opens there, in which you enter the same data (provider, key, model) once more. This then also applies to all pages. For calculation exercises there are four hint levels, with the complete solution only on the fourth click.
:::
