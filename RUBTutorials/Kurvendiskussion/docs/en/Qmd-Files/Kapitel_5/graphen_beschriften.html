Labeling graphs

Welcome to the final chapter!
Here, everything from the previous sections is brought together. Our goal is to develop a single, powerful Python program that analyzes a function thoroughly and displays all its important features – intercepts, extrema, inflection points and asymptotes – in one clear graph.

Step 1: The basic framework – plotting a function

Everything starts with being able to display a function graphically. The knowledge from the section Creating Graphs can help you lay the foundation here.

NoteReminder: creating graphs

In the section Creating Graphs we learned how to plot a function with numpy and matplotlib. The basic procedure was:

  1. Define variables/the function with sympy.
  2. Generate a series of x-values with numpy.linspace.
  3. Calculate the y-values.
  4. Draw the graph with matplotlib.pyplot.plot.

Here is an overview of the advantages/disadvantages of the different objects.

  • String object: A string is a sequence of characters. That means when the function is given, Python treats it like any other word.

  • SymPy object: With a function stored like this, you can work algebraically, i.e. compute zeros and derivatives.
  • NumPy object: A function stored like this is very good for calculating; it is stored in efficient vector form so that calculations can be carried out as efficiently as possible.
x = sympy.symbols('x')

This variant was used frequently in the tutorial; \(f\) is a SymPy object here, because \(f\) contains a variable that was explicitly defined as a SymPy variable beforehand.

f_str="x**3 - 6*x**2 + 9*x"

In this case, f_str is a function stored as a string object.

f_str="x**3 - 6*x**2 + 9*x"
f_sym = sympy.sympify(f_str)

sympy.sympify creates a SymPy object from the string (identical to the first example).

f_np = sympy.lambdify(x, f_sym, 'numpy')

sympy.lambdify is a kind of translator that turns objects into another type of object; in this case, \(f_{sym}\) is translated into numpy based on the variable \(x\), i.e. \(f_{np}\) is a NumPy object.

Step 2: Calculating and marking special points

The goal of this section is to automatically mark all relevant points in a graph, so that ideally the users only have to enter the function and the program does the rest.
This especially means that zeros, extrema/saddle points, inflection points and the y-intercept should be drawn in.

NoteNote on step 2

Note: for all parts of step 2, you can calculate a relevant x-value and then determine the y-value with \(f(x_{\text{relevant value}})\). All relevant points of one kind can be written into the same list of variables and plotted, so that the matching term also appears in their label and in the legend.
E.g. \(x_{zero} =\{x_1,\dots,x_n\} \quad \text{and} \quad y_{zero} =\{f(x_1),\dots,f(x_n)\}\) should be such that \(\forall \quad x_i \in x_{zero}\): \(f(x_i)=0\).

In all programs, \(f(x)= x^3 - 6x^2 + 9x\) is only meant as an example; of course, the programs should work for as many functions as possible, or at least for many different ones.

Step 3: Drawing asymptotes

As already discussed in the sections Asymptotes and End Behavior, some functions have asymptotes, so for this part of the tutorial you should definitely look at those sections.

NoteReminder: finding asymptotes
  • Vertical asymptotes: zeros of the denominator that are not zeros of the numerator. (sympy.fraction, sympy.solve)
  • Horizontal asymptotes: limit of f(x) for x -> oo and x -> -oo. (sympy.limit)
  • Oblique asymptotes: result of the polynomial division if numerator degree = denominator degree + 1. (sympy.div)

Calculating and displaying asymptotes

Since the function used above as a test has no asymptotes, we look at the function \(g(x) = \frac{2x^2 - 1}{x^2 - 4}\) here.
Your task now is to write a program that carries out the following steps:

  1. Calculate the vertical and horizontal asymptotes.
  2. Draw the asymptotes use dashed lines or similar to tell them apart
  3. Bonus: Make sure the graph has a gap at the vertical asymptotes and no connecting line is drawn.
NoteTip: asymptote

Maybe you have already become aware of the problem and are therefore looking at the tips; otherwise, try your hand at the program a little before reading this.

Tips for plotting asymptotes

It is not trivial to draw the asymptotes, and there are several ways to do it

  1. Calculate the asymptote function and then plot it as a function.
  2. Draw horizontal/vertical lines at the right places with plt.axhline() and plt.axvline().

Why would you do 2.? Unfortunately, there is a problem when plotting with matplotlib, especially for the vertical asymptote: \(x=a\) cannot easily be plotted, but a vertical line (plt.axvline()) can be drawn quite easily.

For the oblique asymptote, however, 2. cannot be used, since we are not looking for a horizontal/vertical line but either an oblique line or a curve; for both, the only way is to actually plot the asymptote function.

Tip for a clean graphical representation

You will notice that matplotlib tries to draw a continuous line, even across the vertical asymptote. That does not look nice.

To prevent this, you can use a trick:

  • Find the x-values that lie very close to your asymptote (near the zero of the denominator).
  • Replace the corresponding y-values at these points with np.nan (Not a Number).
  • matplotlib then automatically draws a gap in the graph.

A code snippet for this could look like this:

y_vals[np.abs(x_vals - asymptote_x_value) < 0.1] = np.nan

The code makes sure that the y-values within a distance of 0.1 around the x-value where there is a gap in the domain are not drawn.

### Plotten der Basisfunktion

Ein kleiner Startcode von dem aus du den Rest des Kapitels erarbeiten sollst (mit Tipps natürlich!).

```{pyodide-python}
#| label: beschriften-startcode
import numpy as np
import matplotlib.pyplot as plt
import sympy
x = sympy.symbols('x')
f = x**3 - 6*x**2 + 9*x

f_str="x**3 - 6*x**2 + 9*x"
f_sym = sympy.sympify(f_str) #simpify macht aus einem String eine sympy Funktion
f_np = sympy.lambdify(x, f_sym, 'numpy')#lambdify macht aus einer sympy Funktion eine numpy Funktion (damit können Rechnungen deutlich schneller durchgeführt werden)

x_vals = np.linspace(-1, 5, 400)
y_vals = f_np(x_vals)
plt.plot(x_vals, y_vals)
plt.title('Basisfunktion')
plt.xlabel('x-Achse')
plt.ylabel('y-Achse')
plt.grid(True)
plt.show()
```

</details>

::: {.callout-note title="Hinweis zu unterschiedlichen Objektformen in Python" collapse="true"}
Im obigen Code sind alle in diesem Tutorial vorgekommenen Varianten eine Funktion in Python einzuspeisen, noch einmal aufgeführt.  
Ein Überblick, was die unterschiedlichen Objekte für Vor-/Nachteile haben.  

*   `String-Objekt:` Ein String ist eine Aneinanderreihung von Zeichen. Das heißt wenn die Funktion angegeben wird, ist sie wie ein beliebiges Wort für Python. 
     * Dies ist vor allem wichtig, wenn es darum geht eine Eingabe des Nutzers außerhalb des Codes abzufragen. Das heißt, wenn ich will, dass die Nutzenden vom Programm die Frage gestellt bekommen "Welche Funktion willst du untersuchen?" 
     * Mit `input()` geht das auch hier auf der Website (siehe [Definitionsbereich](../Kapitel_1/definitionsbereich.qmd)): Die Nutzenden tippen die Funktion in das Eingabefeld unter dem Code-Block, Python bekommt sie als String und nach dem Durchlauf des Programms werden alle relevanten Eigenschaften der Funktion angezeigt.
*   `Sympy-Objekt:` Mit einer Funktion die so in Python gespeichert ist kann algebraisch gearbeitet werden, heißt damit können Nullstellen berechnet, Ableitungen bestimmt werden können.
*   `Numpy-Objekt:`  Mit einer so gespeicherten Funktion kann sehr gut gerechnet werden, hier wird die Funktion in effektiver Vektorschreibweise gespeichert damit Rechnungen möglichst effektiv durchgeführt werden können.

```python
x = sympy.symbols('x') 
f = x**3 - 6*x**2 + 9*x
```

Diese Variante wurde häufig im Tutorial genutzt, $f$ ist hierbei ein `Sympy-Objekt`, da in der Variable $f$ eine Variable vorkommt, die vorher explizit als `Sympy-Variable` definiert wird.  

```python
f_str="x**3 - 6*x**2 + 9*x"
```

In diesem Fall ist f_str eine Funktion, die als `String-Objekt` gespeichert ist.
```python
f_str="x**3 - 6*x**2 + 9*x"
f_sym = sympy.sympify(f_str) 
```

Durch `sympy.sympify` wird aus dem String ein `Sympy-Objekt` (identisch mit dem ersten Beispiel) erstellt.
```python
f_np = sympy.lambdify(x, f_sym, 'numpy')  
```

`sympy.lambdify` ist eine Art Übersetzer mit dem Objekte in einen anderen Objekttypen verwandelt werden, in diesem Fall wird $f_{sym}$ basierend auf der Variable $x$ in `numpy` übersetzt, das heißt $f_{np}$ ist ein `Numpy-Objekt`.

:::

## Schritt 2: Besondere Punkte berechnen und einzeichnen

Das Ziel dieses Abschnittes ist es, in einem Graphen alle relevanten Punkte automatisch einzuzeichnen, so dass idealerweise die Nutzenden nur die Funktion eingeben müssen und der Rest automatisch vom Programm gemacht wird.  
Das heißt vor allem auch, dass Nullstellen, Extrempunkte/Sattelpunkte und Wendepunkte und der y-Achsenabschnitt eingezeichnet werden sollen.  

::: {.callout-note title="Hinweis Schritt 2" collapse="true"}
**Hinweis**, bei allen Teilen des Schritt 2 gilt. Es kann ein relevanter x-Wert berechnet werden und dann mit $f(x_{relevanter Wert})$ der y-Wert bestimmt werden. Alle relevanten Punkte einer Gattung können in die gleiche Variablenliste reingeschrieben werden und geplottet werden, so dass in deren Label und der Legende auch der passende Begriff angegeben wird.   
Z.B. sollten $x_{nullstelle} =\{x_1,\dots,x_n\} \quad \text{und} \quad y_{nullstelle} =\{f(x_1),\dots,f(x_n)\}$ derart sein, dass $\forall \quad x_i \in x_{nullstelle}$ gilt $f(x_i)=0$.  

_Bei allen Programmen soll $f(x)= x^3 - 6x^2 + 9x$ nur als Beispiel fungieren, natürlich sollten die Programme möglichst für alle Funktionen, oder mindestens sehr viele unterschiedliche Funktionen funktionieren._

```{pyodide-python}
import numpy as np
import matplotlib.pyplot as plt
import sympy

# --- 1. Definitionen ---
# Eine andere Funktion als in den Aufgaben oben: Hier liegen Nullstellen,
# Hochpunkt, Tiefpunkt und Wendepunkt schön weit auseinander.
# Probier ruhig auch x**3 - 6*x**2 + 9*x aus den Aufgaben aus.
x = sympy.symbols('x')
funktion_str = "x**3 - 3*x**2 - 9*x + 2"
f_sym = sympy.sympify(funktion_str)

# --- 2. Berechnungen der besonderen Punkte ---
# Ableitungen
f_prime = sympy.diff(f_sym, x)
f_double_prime = sympy.diff(f_prime, x)

# Nullstellen
nullstellen_x = [float(ns) for ns in sympy.solveset(f_sym, x, domain=sympy.S.Reals)]
nullstellen_y = [0.0] * len(nullstellen_x) # y ist für Nullstellen immer 0

# Extrempunkte, mit f'' in Hoch- und Tiefpunkte aufgeteilt
extrema_x = [float(ex) for ex in sympy.solveset(f_prime, x, domain=sympy.S.Reals)]
hoch_x = [ex for ex in extrema_x if f_double_prime.subs(x, ex) < 0]
tief_x = [ex for ex in extrema_x if f_double_prime.subs(x, ex) > 0]
hoch_y = [float(f_sym.subs(x, ex)) for ex in hoch_x]
tief_y = [float(f_sym.subs(x, ex)) for ex in tief_x]

# Wendepunkte
wendepunkte_x = [float(wx) for wx in sympy.solveset(f_double_prime, x, domain=sympy.S.Reals)]
wendepunkte_y = [float(f_sym.subs(x, wx)) for wx in wendepunkte_x]

# Y-Achsenabschnitt
y_achsenabschnitt_x = [0.0]
y_achsenabschnitt_y = [float(f_sym.subs(x, 0))]

# --- 3. Plotten ---
# Den Ausschnitt so wählen, dass alle besonderen Punkte gut zu sehen sind
alle_x = nullstellen_x + extrema_x + wendepunkte_x + y_achsenabschnitt_x
alle_y = nullstellen_y + hoch_y + tief_y + wendepunkte_y + y_achsenabschnitt_y
x_min, x_max = min(alle_x) - 1, max(alle_x) + 1
rand_y = 0.3 * (max(alle_y) - min(alle_y))

x_vals = np.linspace(x_min, x_max, 400)
f_np = sympy.lambdify(x, f_sym, 'numpy')
y_vals = f_np(x_vals)

plt.plot(x_vals, y_vals, label=f'f(x) = {f_sym}')

# Besondere Punkte einzeichnen
plt.scatter(nullstellen_x, nullstellen_y, color='red', label='Nullstellen')
plt.scatter(hoch_x, hoch_y, color='green', marker='^', s=80, label='Hochpunkte')
plt.scatter(tief_x, tief_y, color='green', marker='v', s=80, label='Tiefpunkte')
plt.scatter(wendepunkte_x, wendepunkte_y, color='purple', label='Wendepunkte')
plt.scatter(y_achsenabschnitt_x, y_achsenabschnitt_y, color='blue', label='Y-Achsenabschnitt')

# --- 4. Layout ---
plt.ylim(min(alle_y) - rand_y, max(alle_y) + rand_y)
plt.title('Simple Lösung')
plt.xlabel('x-Achse')
plt.ylabel('y-Achse')
plt.grid(True)
plt.legend(loc='upper center', bbox_to_anchor=(0.5, -0.15), ncol=3, fontsize='small')  # Legende unter dem Plot
plt.tight_layout()
plt.show()
```

<details>
<summary> Tipps für das Plotten von Asymptoten </summary>

Es ist nicht trivial die Asymptoten einzuzeichnen und gibt mehrere Möglichkeiten  

1.  Die Asymptotenfunktion berechnen und dann als Funktion plotten.
2.  Horizontale/Vertikale Linien einzeichnen mit `plt.axhline()` und `plt.axvline()` an den richtigen Stellen. 

Warum sollte man 2. machen? Es gibt leider vor allem bei der vertikalen Asymptote ein Problem mit dem plotting per `matplotlib`, $x=a$ kann nicht so ohne weiteres geplottet werden, eine vertikale Linie (`plt.axvline()`) lässt sich jedoch recht leicht plotten.  

Bei der schiefen Asymptote lässt sich nun aber 2. nicht anwenden, da hier keine horizontale/vertikale Linie gesucht wird, sondern entweder eine schiefe Gerade oder eine Kurve, bei beiden Möglichkeiten hilft nur die Asymptotenfunktion tatsächlich zu plotten.

</details>

<details>
<summary> Tipp für eine saubere grafische Darstellung </summary>

Du wirst feststellen, dass `matplotlib` versucht, eine durchgehende Linie zu zeichnen, auch über die vertikale Asymptote hinweg. Das sieht nicht schön aus.

Um das zu verhindern, kannst du einen Trick anwenden:

*   Finde die x-Werte, die sehr nah an deiner Asymptote liegen. (Nahe der bestimmten Nullstelle des Nenners)
*   Ersetze die zugehörigen y-Werte an diesen Stellen durch `np.nan` (Not a Number).
*   `matplotlib` zeichnet dann automatisch eine Lücke im Graphen.

Ein Code-Schnipsel dazu könnte so aussehen:
```python
y_vals[np.abs(x_vals - asymptote_x_wert) < 0.1] = np.nan
```

_Der Code sorgt dafür, dass die Y-Werte in einem Betragsabstand von 0,1 um den x Wert an dem eine Definitionslücke existiert nicht gezeichnet werden._

</details>

```{pyodide-python}
import numpy as np
import matplotlib.pyplot as plt
import sympy

# --- 1. Definitions ---
# A different function than in the exercises above: here the zeros,
# maximum, minimum and inflection point are nicely spread out.
# Feel free to try x**3 - 6*x**2 + 9*x from the exercises as well.
x = sympy.symbols('x')
function_str = "x**3 - 3*x**2 - 9*x + 2"
f_sym = sympy.sympify(function_str)

# --- 2. Calculating the special points ---
# Derivatives
f_prime = sympy.diff(f_sym, x)
f_double_prime = sympy.diff(f_prime, x)

# Zeros
zeros_x = [float(z) for z in sympy.solveset(f_sym, x, domain=sympy.S.Reals)]
zeros_y = [0.0] * len(zeros_x) # y is always 0 for zeros

# Extrema, split into maxima and minima using f''
extrema_x = [float(ex) for ex in sympy.solveset(f_prime, x, domain=sympy.S.Reals)]
max_x = [ex for ex in extrema_x if f_double_prime.subs(x, ex) < 0]
min_x = [ex for ex in extrema_x if f_double_prime.subs(x, ex) > 0]
max_y = [float(f_sym.subs(x, ex)) for ex in max_x]
min_y = [float(f_sym.subs(x, ex)) for ex in min_x]

# Inflection points
inflection_x = [float(ix) for ix in sympy.solveset(f_double_prime, x, domain=sympy.S.Reals)]
inflection_y = [float(f_sym.subs(x, ix)) for ix in inflection_x]

# y-intercept
y_intercept_x = [0.0]
y_intercept_y = [float(f_sym.subs(x, 0))]

# --- 3. Plotting ---
# Choose the view so that all special points are clearly visible
all_x = zeros_x + extrema_x + inflection_x + y_intercept_x
all_y = zeros_y + max_y + min_y + inflection_y + y_intercept_y
x_min, x_max = min(all_x) - 1, max(all_x) + 1
margin_y = 0.3 * (max(all_y) - min(all_y))

x_vals = np.linspace(x_min, x_max, 400)
f_np = sympy.lambdify(x, f_sym, 'numpy')
y_vals = f_np(x_vals)

plt.plot(x_vals, y_vals, label=f'f(x) = {f_sym}')

# Mark the special points
plt.scatter(zeros_x, zeros_y, color='red', label='Zeros')
plt.scatter(max_x, max_y, color='green', marker='^', s=80, label='Maxima')
plt.scatter(min_x, min_y, color='green', marker='v', s=80, label='Minima')
```

## Step 3: Drawing asymptotes

As already discussed in the sections [Asymptotes](../Kapitel_3/asymptoten.qmd) and [End Behavior](../Kapitel_3/globalverhalten.qmd), some functions have asymptotes, so for this part of the tutorial you should definitely look at those sections.

::: {.callout-note title="Reminder: finding asymptotes" collapse="true"}
*   **Vertical asymptotes:** zeros of the denominator that are not zeros of the numerator. (`sympy.fraction`, `sympy.solve`)
*   **Horizontal asymptotes:** limit of `f(x)` for `x -> oo` and `x -> -oo`. (`sympy.limit`)
*   **Oblique asymptotes:** result of the polynomial division if numerator degree = denominator degree + 1. (`sympy.div`)
:::

1.  Calculate the asymptote function and then plot it as a function.
2.  Draw horizontal/vertical lines at the right places with `plt.axhline()` and `plt.axvline()`. 

Why would you do 2.? Unfortunately, there is a problem when plotting with `matplotlib`, especially for the vertical asymptote: $x=a$ cannot easily be plotted, but a vertical line (`plt.axvline()`) can be drawn quite easily.  

For the oblique asymptote, however, 2. cannot be used, since we are not looking for a horizontal/vertical line but either an oblique line or a curve; for both, the only way is to actually plot the asymptote function.

</details>

<details>
<summary> Tip for a clean graphical representation </summary>

You will notice that `matplotlib` tries to draw a continuous line, even across the vertical asymptote. That does not look nice.

To prevent this, you can use a trick:

*   Find the x-values that lie very close to your asymptote (near the zero of the denominator).
*   Replace the corresponding y-values at these points with `np.nan` (Not a Number).
*   `matplotlib` then automatically draws a gap in the graph.

A code snippet for this could look like this:
```python
y_vals[np.abs(x_vals - asymptote_x_value) < 0.1] = np.nan
```

_The code makes sure that the y-values within a distance of 0.1 around the x-value where there is a gap in the domain are not drawn._

</details>

```{pyodide-python}
    # Check whether the input is a valid number
```

```{pyodide-python}
all_x_points = zeros_x + extrema_x + inflection_x

if all_x_points:
    # Find min/max and calculate the buffer
    x_min_auto = min(all_x_points)
    x_max_auto = max(all_x_points)
    buffer = (x_max_auto - x_min_auto) * 0.2 # 20% buffer
    
    # Set the final plot limits
    x_plot_min = x_min_auto - buffer
    x_plot_max = x_max_auto + buffer
else:

    x_plot_max = 5
```
