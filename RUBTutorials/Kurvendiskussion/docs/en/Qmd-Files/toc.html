      This section explains how this website works and shows you what the Python code blocks can do. You can also see here how to create new Python blocks, how your code is saved and how to set up AI feedback.

    • Short description:

  • Drawing Graphs
    • Short description:
      The tutorial ends with visualization. This chapter describes how a graph can generally be displayed, and also how points can be marked and labeled in a plot (extrema, inflection points, asymptotes).

# Kapitelübersicht

*   **[Startseite](index.qmd)**
    *   *Kurzbeschreibung:*  
    Dieser Abschnitt soll dir erklären, wie diese Website funktioniert und dir die Möglichkeiten zeigen, die durch die Python-Codeblöcke gegeben werden. Auch kannst du hier sehen, wie du neue Python-Blöcke erzeugst, wie dein Code gespeichert wird und wie du KI-Feedback einrichtest.

---

*   **[Python Grundlagen](grundlagen.qmd)**
    *   *Kurzbeschreibung:*  
    Eine Wiederholung der Python-Grundlagen (Variablen, Fallunterscheidungen, Datentypen, Listen, Funktionen, Schleifen, Bibliotheken), die im restlichen Tutorial gebraucht werden. Einige Aufgaben werden hier automatisch geprüft.

---


*   **[Definitionsbereiche und Wertebereiche](Kapitel_1/index.qmd)**
    *   *Kurzbeschreibung:*  
    Dieser Abschnitt teilt sich in Definitionsbereich und Wertebereichuntersuchung auf. In den jeweiligen Abschnitten wird gezeigt, wie die jeweiligen Bereiche einer Funktion mit Hilfe von Python bestimmt werden können.

---

*   **[Symmetrie und Achsenschnittpunkte](Kapitel_2/index.qmd)**
    *   *Kurzbeschreibung:*  
    Erfahre hier, wie du Funktionen auf Symmetrieeigenschaften (Achsensymmetrie zur y-Achse, Punktsymmetrie zum Ursprung) untersuchst und die Schnittpunkte mit der x-Achse (Nullstellen) sowie der y-Achse in/mit Python bestimmst.

---

*   **[Globalverhalten und Asymptoten](Kapitel_3/index.qmd)**
    *   *Kurzbeschreibung:*  
    Dieser Teil des Tutorials zeigt dir, wie du das Verhalten einer Funktion im Unendlichen mit Python bestimmst.
    Auch wird dir hier gezeigt, wie eine Funktion auf (die) unterschiedliche(-n) Asymptoten (waagerecht, senkrecht, schief) untersuchst und wie du das Ganze von Python ausgeben lassen kannst.

---

*   **[Monotonie und Krümmungsverhalten](Kapitel_4/index.qmd)**
    *   *Kurzbeschreibung:*  
    Lerne, wie du mithilfe der Ableitungen das Monotonieverhalten (steigend/fallend), Extrempunkte (Hoch-/Tiefpunkte), das Krümmungsverhalten (konvex/konkav) und Wendepunkte einer Funktion mit Python untersuchst.

---

*   **[Graphen zeichnen](Kapitel_5/index.qmd)**
    *   *Kurzbeschreibung:*  
    Als Abschluss des Tutorials geht es um die Visualisierung.
    In diesem Kapitel geht es darum, zu beschreiben, wie ein Graph i.A. dargestellt werden kann, aber auch, wie in einer Darstellung Punkte markiert und beschriftet werden können (Extrem-, Wendestellen, Asymptoten).
