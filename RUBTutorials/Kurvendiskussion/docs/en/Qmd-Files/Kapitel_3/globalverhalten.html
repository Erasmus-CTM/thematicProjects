# Globalverhalten (Das Verhalten im Unendlichen)

In diesem Abschnitt geht es um das **Globalverhalten**, auch **Das Verhalten im Unendlichen** genannt.  
Es wird betrachtet, wie sich die Funktionswerte $f(x)$ verhalten, wenn die $x$-Werte sehr groß (gegen $+\infty$) oder sehr klein (gegen $-\infty$) werden, das heißt wir betrachten die **Grenzwerte (Limes)**:

$$ \lim_{x \to \infty} f(x) \quad \text{und} \quad \lim_{x \to -\infty} f(x) $$

Das Ergebnis dieser Untersuchung verrät uns, ob sich der Graph der Funktion für große/kleine $x$-Werte einer bestimmten Zahl nähert (**[horizontale Asymptote](asymptoten.qmd#horizontale-asymptoten)**) oder ob er unbegrenzt weiter steigt oder fällt.

## Globalverhalten mit Python bestimmen

Innerhalb der Python-Bibliothek `sympy` gibt es eine sehr hilfreiche Funktion, die die Berechnung für uns durchführt, nämlich `sympy.limit()`.

```{pyodide-python}
#| read-only: true
import sympy
x = sympy.symbols('x')
f = (2*x**2 + 1) / (x**2 - 3)  # Beispielfunktion

# Diese Funktion berechnet den pos. bzw. neg. Limes von x gegen + bzw. - Unendlich.

limit_pos_oo = sympy.limit(f, x, sympy.oo) #positiver Grenzwert
limit_neg_oo = sympy.limit(f, x, -sympy.oo) #negativer Grenzwert

print(f"Für x -> +oo geht f(x) gegen {limit_pos_oo}")
print(f"Für x -> -oo geht f(x) gegen {limit_neg_oo}")
```

`sympy` schreibt Unendlich als `oo` (zwei kleine o, sieht aus wie $\infty$). Genauso tippst du es auch in den Rechenaufgaben ein.

# End behavior (behavior at infinity)

This section is about the **end behavior**, also called **the behavior at infinity**.  
We look at how the function values $f(x)$ behave when the $x$-values become very large (towards $+\infty$) or very small (towards $-\infty$), i.e. we consider the **limits**:

$$ \lim_{x \to \infty} f(x) \quad \text{and} \quad \lim_{x \to -\infty} f(x) $$

The result tells us whether the graph of the function approaches a certain number for large/small $x$-values (**[horizontal asymptote](asymptoten.qmd#horizontal-asymptotes)**) or whether it keeps rising or falling without bound.

## Determining end behavior with Python

The Python library `sympy` contains a very helpful function that does the calculation for us: `sympy.limit()`.

```{pyodide-python}
#| read-only: true
import sympy
x = sympy.symbols('x')
f = (2*x**2 + 1) / (x**2 - 3)  # example function

# This computes the limit of f for x towards + or - infinity.

limit_pos_oo = sympy.limit(f, x, sympy.oo) #limit towards +infinity
limit_neg_oo = sympy.limit(f, x, -sympy.oo) #limit towards -infinity

print(f"For x -> +oo, f(x) tends to {limit_pos_oo}")
print(f"For x -> -oo, f(x) tends to {limit_neg_oo}")
```

`sympy` writes infinity as `oo` (two lowercase o's, looks like $\infty$). You type it the same way in the calculation exercises.
