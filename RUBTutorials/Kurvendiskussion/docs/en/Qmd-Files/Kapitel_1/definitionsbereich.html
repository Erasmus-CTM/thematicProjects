# Gebrochen-rationale Funktionen

## Definitionslücke im Nenner bestimmen

Bei gebrochen-rationalen Funktionen (Funktionen, die als Bruch zweier Polynome dargestellt werden) ist die Division durch Null nicht definiert. Der Nenner darf also nicht Null werden.

Nun gilt es, einen Algorithmus zu schreiben, welcher die Stellen berechnet, an denen der Nenner Null werden kann.

```{pyodide-python}
#| read-only: true
import sympy
#Definiere X als Variable(Symbol) für Python
x= sympy.symbols('x')

#Bsp:
nenner=x-1

problemstellen=sympy.solve(nenner,x)

print("Die Problemstelle ist bei x=", problemstellen[0])

#sympy.solve() löst die Gleichung nenner=0 nach x auf
#Problemstellen[0] nutzt den ersten Eintrag der Liste an Nullstellen, die durch sympy.solve bestimmt wird.


```

Bevor du programmierst, zur Kontrolle einmal von Hand: Gib alle Definitionslücken an, durch Komma getrennt. Die Reihenfolge ist egal.

```{math-exercise}
#| label: definitionsbereich-luecken-hand
#| caption: Definitionslücken von Hand
#| mode: set
Für welche $x$ ist $f(x)=\dfrac{x+1}{x^2-9}$ nicht definiert? $x \in \{$ __[3, -3] $\}$
```

    luecken = []
    for s in alle_nullstellen:
        # Dein Code hier: Hänge s an luecken an, falls s reell ist
        pass
    return sorted(luecken)

## Nenner aus einer Funktion auslesen

Jetzt wissen wir also, wie wir bei einem bekannten Nenner bestimmen können, wann dieser Null wird.
Den Nenner direkt anzugeben ist aber zweifelsfrei nicht unbedingt sinnvoll.

Daher betrachten wir jetzt, wie aus einer gegebenen Funktion der Nenner bestimmt werden kann.

In einem weiteren Schritt kann später die Eingabe durch die das Programm nutzenden Person im Terminal eingegeben werden und diese Ausgabe wird dann verarbeitet (ein möglicher Nenner ausgelesen und der Definitionsbereich bestimmt).

**Beispiel:** 
$$
f(x)= \frac{1}{x-2}
$$

Es geht nun erst einmal darum, eine Funktion zu schreiben, welche bei diesem  Beispiel den Nenner erkennt.


```{pyodide-python}
#| read-only: true
import sympy

x = sympy.symbols('x')

funktion_string = "1/(x-2)" #definiert unsere Funktion als Python-Variable
f = sympy.sympify(funktion_string) #wandelt unsere Funktion in ein Sympy-Objekt um, welches wir dann als Variable f weiterbenutzen

nenner = sympy.fraction(f)[1] #Da Sympy nun die Funktion als Objekt erkennt, kann Zähler/Nenner differenziert werden. [0] ist Zähler [1] der Nenner.

print(f"Der Nenner der Funktion ist: {nenner}")

```

### Funktion eingeben lassen und daraus den Definitionsbereich bestimmen

Ideal wäre es, wenn nun ein Nutzer die Funktion eingeben würde und unser Programm aus dem Input direkt den Definitionsbereich bestimmen würde.
Genau dafür gibt es in Python den Befehl `input()`: Das Programm hält an, unter dem Code-Block erscheint ein Eingabefeld, und was du dort eintippst (bestätigt mit Enter), bekommt das Programm als Text zurück. `sympy.sympify()` macht aus diesem Text dann wieder eine Funktion.
Führe den Block aus und gib zum Beispiel `x**2/(x-4)` ein.

::: {.callout-note title="Falls input() nicht funktioniert" collapse="true"}
`input()` braucht eine besondere Sicherheitseinstellung des Browsers, die die Seite beim ersten Laden selbst einschaltet. Steht unter dem Block ein Hinweis, dass `input()` nicht verfügbar ist, lade die Seite einmal neu. Klappt es dann immer noch nicht (manche Browser-Einstellungen verhindern das), ersetze die `input(...)`-Zeile durch deine Funktion als Text, zum Beispiel `funktion_eingabe = "x**2/(x-4)"`.
:::


```{pyodide-python}
#| read-only: true
import sympy

print("Hallo! Dieses Programm kann dir den  Definitionsbereich einer Funktion ausgeben.")

x = sympy.symbols('x')

funktion_eingabe = input("Gib deine Funktion ein, z. B. x**2/(x-4): ") #Das Programm wartet hier auf deine Eingabe.

 
try: #Versuche Eingabe als Sympy Ausdruck zu interpretieren und Nullstelle zu bestimmen
    f = sympy.sympify(funktion_eingabe)
    
    zaehler , nenner = sympy.fraction(f) 

    alle_problemstellen = sympy.solve(nenner, x)
    # Da auch komplexe Lösungen existieren könnten, wir uns aber nur mit reellen beschäftigen wollen:
    reelle_problemstellen = [s for s in alle_problemstellen if s.is_real]

    print(f"Der Nenner der Funktion ist: {nenner}")

    if not reelle_problemstellen:
        print("Der Nenner hat keine reellen Nullstellen.")
        print("Definitionsbereich: D = ℝ (alle reellen Zahlen)")
    else:
        # Formatierung der Problemstellen für die Ausgabe
        stellen_str_luecken = ", ".join(map(str, reelle_problemstellen)) 

#map ist hierbei eine Funktion die genutzt wird um alle reelle Problemstellen in einen String umzuschreiben.
#", ".join setzt die einzelnen Problemstellen dann zu einem Text zusammen, mit Komma dazwischen.

        print(f"Definitionslücke(n) bei x = {stellen_str_luecken}")

        # Formatierung für den Definitionsbereich
        if len(reelle_problemstellen) == 1:
            print(f"Definitionsbereich: D = ℝ \\ {{{reelle_problemstellen[0]}}}")
        else:
            stellen_str_domain = ", ".join(map(str, sorted(reelle_problemstellen))) # sorted sortiert die Ausgaben
            print(f"Definitionsbereich: D = ℝ \\ {{{stellen_str_domain}}}")

except (SyntaxError, TypeError, sympy.SympifyError) as e: # Falls es einen Error gab in der Funktionserkennung wird dieser Error ausgegeben
    print(f"Fehler bei der Verarbeitung der Funktion: {e}. Bitte überprüfe deine Eingabe.")
```

## Definitionslücke in der Wurzel bestimmen

Funktionen mit Quadratwurzel im Speziellen (und allgemein Wurzeln mit geradem Wurzelexponent), haben Definitionslücken, wenn unterhalb der Wurzel eine negative Zahl steht. Diese Definitionslücken gibt es nicht in den komplexen Zahlen, aber in den häufig (vor allem in der Schule) verwendeten reellen Zahlen.

Betrachten wir also wie in den gebrochen-rationalen Funktionen zunächst, wie können wir von einem passenden Term auslesen, für welche Bereiche dieser negativ ist.

```{pyodide-python}
#| read-only: true
import sympy

x = sympy.symbols('x')

radikand = x - 2
print(f"Betrachten wir den Radikanden: {radikand}")

bedingung_ungleichung = sympy.solve_univariate_inequality(radikand >= 0, x, relational=True)
bedingung_intervall = sympy.solve_univariate_inequality(radikand >= 0, x, relational=False)
#relational=True gibt die Lösungsmenge als Ungleichung aus, relational=False als Intervall. Der Standardwert ist relational=True (falls relational nicht angegeben wird)

print(f"Die Bedingung lautet: {radikand} >= 0")
print(f"Das gilt für alle x, die folgende Ungleichung erfüllen: {bedingung_ungleichung}")

print(f"Bzw. für alle x in dem folgenden Intervall: {bedingung_intervall}")


```

## Reading the denominator from a function

So now we know how to find out when a known denominator becomes zero.
But having to type in the denominator directly is certainly not very practical.

So let's look at how the denominator can be determined from a given function.

In a further step, the function can later be entered by the person using the program, and this input is then processed (a possible denominator is extracted and the domain is determined).

**Example:** 
$$
f(x)= \frac{1}{x-2}
$$

First of all, we want to write a function that recognizes the denominator in this example.


```{pyodide-python}
#| read-only: true
import sympy

x = sympy.symbols('x')

function_string = "1/(x-2)" #defines our function as a Python variable
f = sympy.sympify(function_string) #turns our function into a SymPy object, which we keep using as the variable f

denominator = sympy.fraction(f)[1] #Since SymPy now recognizes the function as an object, numerator and denominator can be told apart. [0] is the numerator, [1] the denominator.

print(f"The denominator of the function is: {denominator}")

```

### Letting the user enter the function and determining the domain from it

Ideally, a user would type in the function and our program would determine the domain directly from that input.
Python has the command `input()` for exactly this: the program pauses, an input field appears below the code block, and whatever you type there (confirmed with Enter) is returned to the program as text. `sympy.sympify()` then turns this text back into a function.
Run the block and enter, for example, `x**2/(x-4)`.

::: {.callout-note title="If input() does not work" collapse="true"}
`input()` needs a special browser security setting, which the page switches on by itself when it is first loaded. If a note below the block says that `input()` is not available, reload the page once. If it still does not work (some browser settings prevent it), replace the `input(...)` line with your function as text, for example `function_input = "x**2/(x-4)"`.
:::


```{pyodide-python}
#| read-only: true
import sympy

print("Hello! This program can tell you the domain of a function.")

x = sympy.symbols('x')

function_input = input("Enter your function, e.g. x**2/(x-4): ") #The program waits here for your input.

 
try: #Try to interpret the input as a SymPy expression and find the zeros of the denominator
    f = sympy.sympify(function_input)
    
    numerator , denominator = sympy.fraction(f) 

    all_problem_points = sympy.solve(denominator, x)
    # Complex solutions could exist too, but we only want the real ones:
    real_problem_points = [s for s in all_problem_points if s.is_real]

    print(f"The denominator of the function is: {denominator}")

    if not real_problem_points:
        print("The denominator has no real zeros.")
        print("Domain: D = ℝ (all real numbers)")
    else:
        # Formatting the problem points for the output
        gaps_str = ", ".join(map(str, real_problem_points)) 

#map is a function used here to turn every real problem point into a string.
#", ".join then outputs the individual problem points separated by commas.

        print(f"Gap(s) in the domain at x = {gaps_str}")

        # Formatting for the domain
        if len(real_problem_points) == 1:
            print(f"Domain: D = ℝ \\ {{{real_problem_points[0]}}}")
        else:
            domain_str = ", ".join(map(str, sorted(real_problem_points))) # sorted sorts the output
            print(f"Domain: D = ℝ \\ {{{domain_str}}}")

except (SyntaxError, TypeError, sympy.SympifyError) as e: # If there was an error while recognizing the function, it is printed
    print(f"Error while processing the function: {e}. Please check your input.")
```

## Finding gaps caused by a root

Functions with a square root in particular (and roots with an even index in general) have gaps in their domain where the number under the root is negative. These gaps do not exist in the complex numbers, but they do in the real numbers that are commonly used (especially at school).

So, just like with rational functions, let's first look at how we can read off from a suitable term for which values it is negative.

```{pyodide-python}
#| read-only: true
import sympy

x = sympy.symbols('x')

radicand = x - 2
print(f"Let's look at the radicand: {radicand}")

condition_inequality = sympy.solve_univariate_inequality(radicand >= 0, x, relational=True)
condition_interval = sympy.solve_univariate_inequality(radicand >= 0, x, relational=False)
#relational=True returns the solution set as an inequality, relational=False as an interval. The default is relational=True (if relational is not given)

print(f"The condition is: {radicand} >= 0")
print(f"This holds for all x that satisfy the following inequality: {condition_inequality}")

print(f"Or for all x in the following interval: {condition_interval}")


```

## Reading the radicand from a function

This works very much like reading the denominator: first, a function has to be turned into a `SymPy` object. From `SymPy`, Python can then read the radicand by requesting the right argument.

```{pyodide-python}
#| read-only: true
import sympy

x = sympy.symbols('x')

function_string_root = "sqrt(x-2)" #example function
g = sympy.sympify(function_string_root) 

print(f"The function is: {g}")

# You can print all arguments of the function with g.args 
# Try out which argument is always your radicand.

```
