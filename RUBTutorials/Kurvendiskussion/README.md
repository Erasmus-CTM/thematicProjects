# Kurvendiskussion (curve sketching)

A step-by-step course on analysing functions, for students in their first semester.

| Chapter | Content |
|---|---|
| 1 | Domain and range |
| 2 | Symmetry and intercepts, zeros |
| 3 | End behaviour and asymptotes |
| 4 | Derivatives, monotonicity, extrema, curvature, inflection points |
| 5 | Drawing and labelling graphs |

Every chapter mixes short explanations with interactive Python cells (SymPy, Matplotlib), maths answers checked with SymPy (`math-exercise`) and coding exercises with hidden tests (`py-exercise`). German and English.

- Rendered site: `docs/` (serve it locally, see the [overview](../README.md)).
- Build: `python build_multilingual_site.py --no-serve`
