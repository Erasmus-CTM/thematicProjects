# Thematic projects for applied mathematics
This repository contains a collection of project descriptions focused on using mathematical concepts in 'real' applications.

## RUB Tutorials
The folder [RUBTutorials](RUBTutorials/) holds four interactive Quarto tutorials from Ruhr-Universität Bochum: curve sketching, matrices, statistics and a guide to building such material with Quarto.
